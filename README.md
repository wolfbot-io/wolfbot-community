## What is WolfBot Community?

**WolfBot Community** is the free, self-hosted edition of [WolfBot.io](https://wolfbot.io) — automated trading software that runs on **your** machine, connecting to **your** exchange accounts through trade-only API keys. You keep full control of your infrastructure, your keys, and your data.

WolfBot Community gives you the same trading engine behind WolfBot Cloud, without requiring a managed subscription.

- **Free Community Edition** — no subscription, no cloud account required
- **Self-hosted** — runs on your Windows or Linux machine
- **Simulation-first** — test strategies risk-free before going live
- **Smart execution** — limit orders, smart routing, risk controls
- **Multi-broker** — Binance, Bybit, BingX, KuCoin, Bitget, MT5
- **Automatic updates** — stay current with signed releases

## Install in Minutes

### Windows

```
1. Download Setup.exe
2. Double-click → Install
3. Open WolfBot
```

### Linux (Ubuntu/Debian)

```
1. Download .deb
2. sudo dpkg -i wolfbot-setup-*.deb
3. Open WolfBot
```

## Community vs Cloud

| | WolfBot Community | WolfBot Cloud |
|---|---|---|
| **Hosting** | Self-hosted (your machine) | Managed by WolfBot.io |
| **Cost** | Free | Subscription |
| **Infrastructure** | You manage | Fully managed |
| **Setup** | Install & configure | Ready immediately |
| **Updates** | Channel-based auto-update | Automatic |
| **Support** | Community Discussions | Direct support |
