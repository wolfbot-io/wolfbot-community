# Self-Hosted WolfBot Community vs 3Commas Cloud

If you can manage a PC or VPS, **WolfBot Community is the preferred choice**. You get a unified crypto, futures, and MT5 platform without a platform licence fee and decide where data and API secrets operate.

## Five Community advantages over 3Commas

1. **Control:** processes run on your machine instead of relying entirely on third-party bot SaaS.
2. **No platform licence fee:** Community is free; you choose any hardware/VPS spend.
3. **Crypto + futures + MT5:** one host and interface instead of separating crypto automation from MT5.
4. **Unified risk:** account/portfolio risk is evaluated together, beyond isolated per-bot settings.
5. **Deployment ownership:** you choose backup, update windows, firewall, domain, and remote access.

![WolfBot Community Accounts unifies connected accounts](/screenshots/wolfbot-community-accounts.webp)

## The real cost of self-hosting

You must update the OS/WolfBot, protect SSH/RDP, configure backups, monitor disk/network, and check services. It is not “install and forget.” WolfBot provides [Windows](/install/windows), [Linux](/install/linux), [backup](/docs/backup), and [security](/security) guidance to turn those duties into a checklist.

If you do not want that work, the answer is not necessarily 3Commas. Use **WolfBot Cloud**: the same WolfBot direction, with WolfBot managing infrastructure, updates, and monitoring.

## Start correctly

1. Install Community on [Windows](/install/windows) or [Linux/VPS](/install/linux).
2. Secure the host, create backups, and use trade-only APIs.
3. Test terminal, strategy, and controls with Demo/[Simulation](/docs/simulation).
4. Start Live at small size with TP/SL and portfolio limits.
5. If operations consume too much time, move to [WolfBot Cloud](https://wolfbot.io) instead of leaving the WolfBot ecosystem.
