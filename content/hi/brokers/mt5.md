# MT5 को WolfBot Community से कनेक्ट करें

**टेस्ट किया गया संस्करण: WolfBot Community v0.1.0-p12-ghcr-rc21** · आखिरी अपडेट: 2026-08-15

**MT5 सपोर्ट स्टेटस:** स्थिर · डेमो ✅ · लाइव ✅ · टर्मिनल ✅ · स्ट्रेटेजी ✅ · Windows ✅ · Linux ✅

## MT5 पहले से शामिल है

फॉरेक्स, गोल्ड, इंडेक्स, स्टॉक्स/CFD — MT5 मार्केट WolfBot Community का हिस्सा हैं, वही डैशबोर्ड में आपके क्रिप्टो अकाउंट के बगल में। यह Windows और Linux दोनों पर एक जैसे काम करता है, और MT5 ट्रेड करने के लिए आपको कभी भी अलग Windows मशीन की ज़रूरत नहीं पड़ती।

- **Windows पर**, WolfBot आपके पहले से इस्तेमाल हो रहे MetaTrader 5 ऐप से कनेक्ट होता है।
- **Linux पर**, WolfBot आपके अपने ब्राउज़र के अंदर आपके लिए MT5 खोलता है — अलग से कुछ भी इंस्टॉल करने की ज़रूरत नहीं।

## यह गाइड किसके लिए है

MT5 ट्रेडर जो WolfBot Community के साथ अपनी ट्रेडिंग को ऑटोमेट करना चाहते हैं — क्रिप्टो और पारंपरिक मार्केट के लिए आपका एकीकृत प्लेटफ़ॉर्म, आप जो भी OS पहले से चला रहे हैं उस पर।

## आपको क्या चाहिए

- इंस्टॉल किया गया WolfBot Community
- एक MT5 ब्रोकर अकाउंट (डेमो या लाइव)
- Windows पर: इंस्टॉल किया गया [MetaTrader 5](https://www.metatrader5.com/en/download)
- 15 मिनट

## MT5 कनेक्ट करें

1. WolfBot Community खोलें
2. **Exchange Accounts → Add Account → MT5** पर जाएं
3. अपने ब्रोकर अकाउंट में लॉग इन करें (डेमो या लाइव)
   - **Windows:** यह आपके MetaTrader 5 ऐप में होता है
   - **Linux:** यह सीधे WolfBot ब्राउज़र विंडो के अंदर होता है — केवल पहली बार, एक जल्दी वाला एकबारगी सेटअप चरण है (नीचे [तकनीकी उपयोगकर्ताओं के लिए](#तकनीकी-उपयोगकर्ताओं-के-लिए) देखें)
4. WolfBot आपके उपलब्ध सिंबल अपने आप उठा लेता है
5. ट्रेडिंग शुरू करें — Smart Terminal, Bots और Risk Controls सब बिल्कुल उसी तरह काम करते हैं जैसे आपके क्रिप्टो अकाउंट में

> ⚠️ WolfBot को इसके ज़रिए ट्रेड करने के लिए MT5 का लॉग इन होना ज़रूरी है।

## कनेक्शन टेस्ट करें

1. WolfBot में: Smart Terminal → MT5 चुनें
2. MT5 से उपलब्ध सिंबल दिखाई देने चाहिए
3. पहले अपने डेमो अकाउंट पर एक छोटा टेस्ट ऑर्डर लगाएं
4. अपने लाइव MT5 अकाउंट पर स्विच करें और न्यूनतम साइज़ का ऑर्डर लगाएं
5. पुष्टि करें कि ऑर्डर MT5 में दिखाई दे रहा है
6. टेस्ट ऑर्डर रद्द करें

## आप क्या ट्रेड कर सकते हैं

MT5 लगभग हर एसेट क्लास को कवर करता है — WolfBot वही ट्रेड करता है जो आपके ब्रोकर का MT5 अकाउंट देता है, कोई फिक्स्ड लिस्ट नहीं:

- **फॉरेक्स** — EUR/USD, GBP/USD, USD/JPY, और 50+ अन्य पेयर
- **धातुएं** — गोल्ड (XAU/USD), सिल्वर (XAG/USD), अक्सर प्लैटिनम और पैलेडियम भी
- **एनर्जी** — क्रूड ऑयल, नैचुरल गैस (ब्रोकर पर निर्भर)
- **इंडेक्स** — US30, NAS100, S&P 500, DAX, और अधिक
- **स्टॉक्स/CFD** — व्यक्तिगत कंपनी शेयर, अक्सर हज़ारों सिंबल (ब्रोकर पर निर्भर)
- **कृषि कमोडिटी** — गेहूं, मक्का, कॉफ़ी, चीनी और अन्य (ब्रोकर पर निर्भर)
- **क्रिप्टो CFD** — जहां आपका ब्रोकर देता है

> सटीक इंस्ट्रूमेंट उपलब्धता आपके MT5 ब्रोकर पर निर्भर करती है, WolfBot पर नहीं — अपने अकाउंट से ट्रेड किए जा सकने वाले पूरे सिंबल लिस्ट के लिए अपने MT5 टर्मिनल में **Market Watch** देखें।

## गोल्ड ट्रेडिंग के लिए MT5

गोल्ड (XAU/USD) ऑटोमेशन के लिए सबसे लोकप्रिय MT5 इंस्ट्रूमेंट में से एक है:

1. अपने MT5 ब्रोकर को XAU/USD के साथ कनेक्ट करें
2. WolfBot में: Smart Terminal → XAU/USD
3. रिस्क कॉन्फ़िगर करें (गोल्ड अस्थिर होता है — छोटे साइज़ से शुरू करें)
4. लाइव जाने से पहले डेमो अकाउंट पर टेस्ट करें

## आम समस्याएं

| समस्या | समाधान |
|---|---|
| MT5 कनेक्ट नहीं हो रहा | सुनिश्चित करें कि आप MT5 में अपने ब्रोकर अकाउंट में लॉग इन हैं, फिर दोबारा कोशिश करें |
| "Symbol not available" | अपने ब्रोकर के उपलब्ध इंस्ट्रूमेंट जांचें |
| "Automated trading disabled" | MT5 में: Tools → Options → Expert Advisors → Allow Automated Trading |
| "Order rejected by broker" | न्यूनतम लॉट साइज़ और ट्रेडिंग घंटे जांचें |

## तकनीकी उपयोगकर्ताओं के लिए

नीचे दिए विवरण उन लोगों के लिए हैं जो यह समझना चाहते हैं कि MT5 ब्रिज ठीक-ठीक कैसे काम करता है, या जो Linux सेटअप चरण को टर्मिनल से करना पसंद करते हैं। WolfBot में MT5 इस्तेमाल करने के लिए यह पढ़ना ज़रूरी नहीं है — सामान्य फ्लो के लिए ऊपर [MT5 कनेक्ट करें](#mt5-कनेक्ट-करें) देखें।

### ब्रिज कैसे काम करता है

**Windows** — MT5 अपने खुद के नेटिव ऐप के रूप में चलता है; WolfBot सीधे इससे ब्रिज करता है:

```text
WolfBot Community → MT5 ब्रिज (लोकल) → MetaTrader 5 टर्मिनल (आपकी इंस्टॉल) → MT5 ब्रोकर सर्वर
```

**Linux** — WolfBot खुद MT5 टर्मिनल को एक कंटेनर के अंदर चलाता है, और आपको इसमें एक ब्राउज़र विंडो (VNC) देता है:

```text
WolfBot Community → MT5 ब्रिज कंटेनर (टर्मिनल + VNC + RPyC) → ब्राउज़र विंडो → MT5 ब्रोकर सर्वर
```

किसी भी तरह से, ब्रिज केवल MT5 *के ज़रिए* ही आपके ब्रोकर से बात करता है — WolfBot कभी भी सीधे आपके ब्रोकर से कनेक्ट नहीं होता।

### Linux: एकबारगी टर्मिनल सेटअप

WolfBot का MT5 कंटेनर बेस इंस्टॉल से शुरू नहीं होता (हर Community यूज़र MT5 ट्रेड नहीं करता), इसलिए पहली बार, इसे इस तरह शुरू करें:

```bash
docker compose \
  -f /opt/wolfbot/compose/wolfbot-compose.json \
  -f /opt/wolfbot/compose/compose.mt5.yaml \
  up -d
```

फिर अपने ब्राउज़र में **`http://127.0.0.1:8090/mt5-vnc/`** खोलें (पासवर्ड `wolfbot`, या जो भी आपने `MT5_VNC_PASSWORD` के ज़रिए सेट किया हो) और वहां अपने ब्रोकर में लॉग इन करें — यह वही ब्राउज़र विंडो है जो WolfBot का MT5 फ्लो बाद में इस्तेमाल करता है। एक्सेस हमेशा ऑन और अप्रतिबंधित है, क्योंकि यह आपकी अपनी मशीन है, कोई शेयर्ड Cloud इंस्टेंस नहीं।

### Windows: ब्रिज कॉन्फ़िगरेशन संदर्भ

| सेटिंग | मान |
|---|---|
| MT5 इंस्टॉलेशन पथ | अपने आप पता लगाया गया (आमतौर पर `C:\Program Files\MetaTrader 5`) |
| अकाउंट टाइप | Demo या Live |
| सिंबल मैपिंग | अपने आप कॉन्फ़िगर |

### आवश्यकताएं

- ट्रेडिंग के दौरान MT5 चलता रहना चाहिए (Windows पर नेटिव, या Linux पर ब्रिज कंटेनर)
- MT5 में Automated Trading (Algo Trading) सक्षम होना चाहिए
- आपकी मशीन ऑन रहनी चाहिए (या VPS इस्तेमाल करें — Windows और Linux दोनों काम करते हैं)
- अभी तक सपोर्टेड नहीं: एक साथ कई MT5 इंस्टेंस, कुछ दुर्लभ ब्रोकर-विशिष्ट सिंबल

### तकनीकी समस्या निवारण

| समस्या | समाधान |
|---|---|
| "MT5 not detected" (Windows) | इंस्टॉलेशन पथ जांचें; MT5 रीस्टार्ट करें |
| VNC पेज लोड नहीं होता (Linux) | पुष्टि करें कि MT5 कंटेनर चल रहा है: `docker compose ... ps` — पहली बार शुरू होने में एक मिनट लग सकता है |
| "Bridge connection failed" | सुनिश्चित करें कि MT5 चल रहा है और लॉग इन है — Windows पर नेटिव, या Linux पर ब्राउज़र सेशन |

### MT5 को 24/7 चलाना

- **Windows:** एक Windows VPS इस्तेमाल करें, MT5 + WolfBot Community इंस्टॉल करें, MT5 में auto-login सक्षम करें, WolfBot को अपने आप शुरू करने के लिए Windows कॉन्फ़िगर करें
- **Linux:** MT5 कंटेनर सक्षम के साथ WolfBot Community चलाने वाला एक Linux VPS इस्तेमाल करें — यह लॉग इन रहता है और किसी भी दूसरी WolfBot सर्विस की तरह ही चलता रहता है, किसी auto-login स्क्रिप्ट की ज़रूरत नहीं
