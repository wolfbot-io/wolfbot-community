# ट्रेड-ओनली API कुंजी गाइड

**टेस्ट किया गया संस्करण: WolfBot Community v0.1.0-beta.9** · आखिरी अपडेट: 2026-08-15

## ट्रेड-ओनली क्यों?

WolfBot Community **नॉन-कस्टोडियल** है — यह कभी भी आपके फंड को होल्ड नहीं करता। यह उन API कुंजियों के ज़रिए एक्सचेंज से कनेक्ट होता है जिन्हें आप कंट्रोल करते हैं। आप इन कुंजियों को कभी भी रद्द कर सकते हैं।

**सुनहरा नियम:** ट्रेडिंग सॉफ़्टवेयर के साथ इस्तेमाल की जाने वाली किसी भी API कुंजी पर कभी भी Withdrawal या Transfer अनुमतियां सक्षम न करें। यह एक सेटिंग किसी भी दूसरी से ज़्यादा क्यों मायने रखती है, यह जानने के लिए [ट्रेड-ओनली API कुंजियां समझाई गईं →](/docs/trade-only-api-keys-explained) देखें।

## ज़रूरी अनुमतियां

WolfBot को केवल ये अनुमतियां चाहिए:

| अनुमति | ज़रूरी | क्यों |
|---|---|---|
| **Trade** (Read-Write) | ✅ हां | ऑर्डर लगाना/रद्द करना, पोज़िशन जांचना |
| **Read** (Read-Only) | ✅ हां | बैलेंस, पोज़िशन, ऑर्डर हिस्ट्री पढ़ना |
| **Withdrawal** | ❌ कभी नहीं | WolfBot फंड नहीं निकालता |
| **Transfer** | ❌ कभी नहीं | WolfBot अकाउंट के बीच ट्रांसफर नहीं करता |

अगर कोई एक्सचेंज बारीक अनुमतियां देता है, तो इन्हें भी बंद करें:
- ❌ **Withdrawal**
- ❌ **Internal Transfer**
- ❌ **Sub-account Transfer**
- ❌ **Earn/Staking** प्रबंधन

## एक्सचेंज के अनुसार

### Binance
1. API Management → Create API
2. सक्षम करें: **Enable Spot & Margin Trading**
3. बंद करें: **Enable Withdrawals**
4. (सुझाव) भरोसेमंद IP तक सीमित करें

### Bybit
1. API Management → Create New Key
2. सक्षम करें: **Trade** अनुमति
3. बंद करें: **Withdrawal**, **Transfer**
4. (सुझाव) IP पता बांधें

### BingX
1. API Management → Create API Key
2. सक्षम करें: **Trade**
3. बंद करें: **Withdrawal**
4. (सुझाव) IP एक्सेस सीमित करें

### KuCoin
1. API Management → Create API
2. Spot Trading के अंतर्गत सक्षम करें: **Trade**
3. बंद करें: **Withdrawal**, **Transfer**
4. एक पासफ़्रेज़ सेट करें (KuCoin के लिए ज़रूरी)

### Bitget
1. API Management → Create API Key
2. सक्षम करें: **Trade**
3. बंद करें: **Withdrawal**
4. (सुझाव) IP बांधें

## अतिरिक्त सुरक्षा सुझाव

### IP बाइंडिंग (सुझाव)
जहां सपोर्टेड हो, API कुंजियों को अपनी मशीन के IP पते से बांधें:
- दूसरी जगहों से इस्तेमाल रोकता है
- IP बदलने पर अपडेट करें
- 24/7 ऑपरेशन के लिए स्टैटिक IP या VPS इस्तेमाल करें

### हर सेवा के लिए अलग कुंजी
- WolfBot Community के लिए एक API कुंजी
- पोर्टफोलियो ट्रैकिंग ऐप के लिए अलग कुंजियां
- व्यक्तिगत इंटीग्रेशन को रद्द करना आसान बनाता है

### नियमित ऑडिट
- हर महीने API कुंजियों की समीक्षा करें
- इस्तेमाल न हो रही कुंजियां हटाएं
- समय-समय पर कुंजियां दोबारा जनरेट करें

### कुंजी स्टोरेज
- API secrets सुरक्षित रूप से स्टोर करें (WolfBot इन्हें लोकली एन्क्रिप्ट करता है)
- कभी भी स्क्रीनशॉट या सपोर्ट मैसेज में कुंजियां साझा न करें
- कुंजियों को cloud notes या ईमेल में स्टोर न करें

## अगर कोई कुंजी लीक हो जाए तो क्या करें?

1. एक्सचेंज पर API कुंजी **तुरंत** डिलीट करें
2. अपने अकाउंट में किसी अनधिकृत गतिविधि की जांच करें
3. एक नई ट्रेड-ओनली कुंजी बनाएं
4. WolfBot को नई कुंजी से अपडेट करें

क्योंकि Withdrawal बंद है, एक लीक हुई ट्रेड-ओनली कुंजी फंड नहीं चुरा सकती — लेकिन यह अनचाही ट्रेड लगा सकती है। हमेशा जल्दी कार्रवाई करें।
