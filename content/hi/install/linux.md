# Ubuntu/Linux पर WolfBot Community इंस्टॉल करें

**टेस्ट किया गया संस्करण: WolfBot Community v0.1.0-p12-ghcr-rc19** · आखिरी अपडेट: 2026-08-15 · Ubuntu 24.04 / Ubuntu 22.04 / Debian 12

## यह गाइड किसके लिए है

जो कोई भी Ubuntu या Debian पर WolfBot Community इंस्टॉल करना चाहता है — **आपको टर्मिनल या Docker जानने की ज़रूरत नहीं है।** नीचे सब कुछ उसी डबल-क्लिक इंस्टॉल का इस्तेमाल करता है जो आप किसी भी दूसरे ऐप के लिए करते हैं; जो लोग पसंद करें उनके लिए आगे कमांड-लाइन विकल्प भी दिया गया है।

## आपको क्या चाहिए

- Ubuntu 22.04 LTS, Ubuntu 24.04 LTS, या Debian 12 (64-बिट)
- कम से कम 4 GB RAM, 4 GB खाली डिस्क स्पेस
- इंटरनेट कनेक्शन
- आपके अकाउंट का पासवर्ड (इंस्टॉल की अनुमति देने के लिए एक बार पूछा जाएगा — यह पूरी तरह सामान्य है, Linux पर हर ऐप इंस्टॉलर यही पूछता है)

> ℹ️ WolfBot को चलने के लिए Docker चाहिए। अगर यह अभी इंस्टॉल नहीं है, तो इंस्टॉलर इसे आपके लिए अपने आप इंस्टॉल कर देता है — हाथ से कुछ भी सेटअप करने की ज़रूरत नहीं।

## चरण 1: डाउनलोड करें

1. [community.wolfbot.io/download](https://community.wolfbot.io/download) पर जाएं
2. **Download for Linux** पर क्लिक करें
3. फ़ाइल `WolfBot-Setup-linux-amd64.deb` आपके **Downloads** फ़ोल्डर में डाउनलोड होगी

## चरण 2: इंस्टॉल करें (डबल-क्लिक, किसी भी दूसरे ऐप की तरह)

1. अपना **Downloads** फ़ोल्डर खोलें और `WolfBot-Setup-linux-amd64.deb` पर **डबल-क्लिक** करें
2. आपके सिस्टम का ऐप इंस्टॉलर विंडो खुलेगा (आमतौर पर "Software Install" या "Package Installer" कहलाता है)
3. **Install** पर क्लिक करें
4. पूछे जाने पर अपना पासवर्ड टाइप करें, फिर Enter दबाएं/OK पर क्लिक करें
5. पूरा होने का इंतज़ार करें — पहली बार में एक-दो मिनट लग सकते हैं, क्योंकि यह बैकग्राउंड में Docker भी सेटअप करता है

बस इतना ही — किसी टर्मिनल की ज़रूरत नहीं।

> **इंस्टॉल विंडो नहीं मिली?** कुछ Ubuntu वर्ज़न डिफ़ॉल्ट रूप से `.deb` फ़ाइलों को इंस्टॉलर की बजाय फ़ाइल आर्काइव व्यूअर में खोलते हैं।
> फ़ाइल पर राइट-क्लिक करें → **Open With** → **Software Install** चुनें (या अगर आपके पास है तो **GDebi Package Installer**) → फिर **Install** पर क्लिक करें।

## चरण 3: WolfBot लॉन्च करें

1. अपना **Applications** मेन्यू खोलें (या Windows/Super की दबाएं और "WolfBot" टाइप करें)
2. **WolfBot** आइकन पर क्लिक करें
3. आपका ब्राउज़र अपने आप WolfBot डैशबोर्ड पर खुल जाएगा

## अपेक्षित परिणाम

- आपके Applications मेन्यू में एक WolfBot आइकन दिखाई देता है
- इस पर क्लिक करने से आपके ब्राउज़र में डैशबोर्ड खुलता है
- डैशबोर्ड का कैपेबिलिटी स्टेटस पेज दिखाता है कि आप कौन से ब्रोकर कनेक्ट कर सकते हैं — शून्य-जोखिम ट्रेडिंग के लिए एक [डेमो अकाउंट](/docs/simulation) से शुरुआत करें

## MT5 के ज़रिए फॉरेक्स, गोल्ड और इंडेक्स ट्रेड करें — Windows की ज़रूरत नहीं

WolfBot Community एक **एकीकृत प्लेटफ़ॉर्म** है: क्रिप्टो एक्सचेंज और MT5 (फॉरेक्स, गोल्ड, इंडेक्स, स्टॉक्स/CFD) एक ही इंटरफ़ेस, एक ही रिस्क इंजन, एक ही पोर्टफोलियो में — Linux पर भी, बिना किसी अलग Windows मशीन या VPS की ज़रूरत के। MT5 WolfBot के बाकी हिस्से के साथ एक असली टर्मिनल के रूप में चलता है, और आप इसे अपने ब्राउज़र से कंट्रोल करते हैं। इसे एक कमांड से एक्टिवेट करें — सटीक चरणों के लिए [MT5 कनेक्ट गाइड](/brokers/mt5) देखें।

## आम गलतियां

| गलती | समाधान |
|---|---|
| डबल-क्लिक करने पर इंस्टॉल की बजाय फ़ाइल आर्काइव खुलता है | फ़ाइल पर राइट-क्लिक करें → Open With → Software Install |
| "Authentication required" प्रॉम्प्ट | यह सामान्य है — अपना सामान्य लॉगिन पासवर्ड डालें |
| Install पर क्लिक करने के बाद कुछ नहीं होता | एक मिनट रुकें — पहली बार Docker सेटअप बैकग्राउंड में चलता है |
| इंस्टॉल के बाद WolfBot नहीं मिल रहा | एक बार लॉग आउट करके फिर लॉग इन करें, या Applications मेन्यू में "WolfBot" खोजें |

## कमांड लाइन पसंद है?

अगर आप टर्मिनल में सहज हैं, तो यह ऊपर दिए गए चरणों जैसा ही काम करता है:

```bash
cd ~/Downloads
sudo apt install ./WolfBot-Setup-linux-amd64.deb
```

`dpkg -i` की बजाय `apt install ./file.deb` इस्तेमाल करने से किसी भी गायब डिपेंडेंसी को एक ही चरण में अपने आप हल कर देता है।

इंस्टॉल के बाद उपयोगी कमांड:

```bash
wolfbot status     # सर्विस चेक करें
wolfbot start      # WolfBot शुरू करें
wolfbot open       # ब्राउज़र में डैशबोर्ड खोलें
wolfbot logs       # लॉग देखें
```

डैशबोर्ड पता: `http://127.0.0.1:8765`

## समस्या निवारण

- **WolfBot आइकन पर क्लिक करने पर कुछ नहीं खुलता** — फ्रेश इंस्टॉल के बाद एक मिनट रुकें (Docker कंटेनर अभी भी शुरू हो रहे हैं), फिर दोबारा कोशिश करें।
- **"Port in use" या डैशबोर्ड लोड नहीं होता** — हो सकता है आपके कंप्यूटर पर कुछ और पोर्ट 8765 का इस्तेमाल कर रहा हो। कैसे जांचें, यह जानने के लिए [समस्या निवारण गाइड](/docs/troubleshooting) देखें।
- अभी भी अटके हुए हैं? पूरी [समस्या निवारण गाइड](/docs/troubleshooting) देखें या [GitHub Discussions](https://github.com/wolfbot-io/wolfbot-community/discussions) में पूछें।

## अनइंस्टॉल करें

अपने सिस्टम का ऐप स्टोर खोलें (जैसे **Ubuntu Software**), "WolfBot" खोजें, और **Remove** पर क्लिक करें — उसी तरह जैसे आप `.deb` फ़ाइल से इंस्टॉल किए गए किसी भी दूसरे ऐप को अनइंस्टॉल करते हैं।

या टर्मिनल के ज़रिए:

```bash
sudo apt remove wolfbot-community
rm -rf ~/.wolfbot    # वैकल्पिक: अपना लोकल WolfBot डेटा भी हटा दें
```
