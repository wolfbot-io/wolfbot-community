# WolfBot Community के साथ शुरुआत करें

**टेस्ट किया गया संस्करण: WolfBot Community v0.1.0-beta.4** · आखिरी अपडेट: 2026-08-15

## स्वागत है! 👋

WolfBot Community एक एकीकृत ट्रेडिंग प्लेटफ़ॉर्म है — क्रिप्टो एक्सचेंज और MT5 ब्रोकर के लिए एक ही इंटरफ़ेस। इसे इंस्टॉल करने से कोई भी एक्सचेंज अकाउंट नहीं बनता और कोई ट्रेड नहीं होती — जब तक आप खुद कोई अकाउंट न जोड़ें, तब तक कुछ भी कनेक्ट नहीं होता। नीचे दिए गए चरणों को क्रम से पूरा करें।

> **एक प्लेटफ़ॉर्म। हर मार्केट।** — क्रिप्टो + फ्यूचर्स + MT5, WolfBot में एकीकृत।

## चरण 1: डैशबोर्ड खोलें

WolfBot Community को लॉन्च करें। आप **कैपेबिलिटी स्टेटस** पेज पर पहुंचेंगे — यह दिखाता है कि आपकी इंस्टॉल में कौन से ब्रोकर और फीचर उपलब्ध हैं, और पुष्टि करता है कि अभी कुछ भी कनेक्ट नहीं है।

## चरण 2: डैशबोर्ड को एक्सप्लोर करें

| भाग | उद्देश्य |
|---|---|
| **पोर्टफोलियो ओवरव्यू** | बैलेंस, लाभ/हानि, पोज़िशन — सभी कनेक्टेड मार्केट में |
| **बॉट्स** | क्रिप्टो और MT5 के लिए ऑटोमेटेड ट्रेडिंग बॉट |
| **स्मार्ट टर्मिनल** | रिस्क कंट्रोल के साथ मैनुअल ट्रेडिंग |
| **रिस्क कंट्रोल्स** | पोज़िशन लिमिट, ड्रॉडाउन सुरक्षा |
| **एक्सचेंज अकाउंट्स** | ब्रोकर कनेक्शन और API कीज़ |

## चरण 3: एक डेमो अकाउंट कनेक्ट करें — शून्य जोखिम

WolfBot में कोई अलग "सिमुलेशन मोड" टॉगल नहीं है। इसकी जगह, आप ब्रोकर का अपना **डेमो/टेस्टनेट अकाउंट** कनेक्ट करते हैं — असली मार्केट डेटा, वर्चुअल फंड, वही इंटरफ़ेस और वही रिस्क इंजन जो आप बाद में लाइव ट्रेडिंग के लिए इस्तेमाल करेंगे।

1. **एक्सचेंज अकाउंट्स → अकाउंट जोड़ें** पर जाएं
2. **Bybit** चुनें और [Bybit डेमो सेटअप के चरण](/brokers/bybit) फॉलो करें — WolfBot आपके द्वारा पेस्ट की गई API कुंजी से खुद ही पहचान लेता है कि यह डेमो है या लाइव
3. अपने डेमो अकाउंट के साथ **स्मार्ट टर्मिनल** आज़माएं
4. देखें कि डैशबोर्ड में पोज़िशन कैसे दिखाई देती हैं

> ✅ डेमो अकाउंट का कोई खर्च नहीं होता और यह कभी भी असली फंड को नहीं छूता — हर सपोर्टेड मार्केट में WolfBot सीखने का सबसे सुरक्षित तरीका।

[पूरी डेमो/सिमुलेशन गाइड →](/docs/simulation)

## चरण 4: असली ट्रेडिंग के लिए अपने मार्केट कनेक्ट करें

जब लाइव जाने के लिए तैयार हों:
1. अपने एक्सचेंज पर एक ट्रेड-ओनली API कुंजी बनाएं
2. एक्सचेंज अकाउंट्स → अकाउंट जोड़ें → ब्रोकर चुनें → कुंजी दर्ज करें
3. छोटी पोज़िशन और सख्त रिस्क कंट्रोल के साथ शुरुआत करें

> ⚠️ हमेशा ऐसी API कुंजियां इस्तेमाल करें जिनमें केवल ट्रेड की अनुमति हो (कोई निकासी नहीं)।
