# बैकअप और रीस्टोर गाइड

**टेस्ट किया गया संस्करण: WolfBot Community v0.1.0-beta.9** · आखिरी अपडेट: 2026-08-15

## बैकअप क्यों करें?

WolfBot आपके कॉन्फ़िगरेशन को लोकली स्टोर करता है: ब्रोकर API कनेक्शन, स्ट्रेटेजी सेटिंग्स, रिस्क पैरामीटर, बॉट कॉन्फ़िगरेशन, और ट्रेडिंग प्राथमिकताएं। एक बैकअप हफ्तों या दिनों के सेटअप काम की सुरक्षा करता है।

---

## बैकअप (Linux)

बैकअप टर्मिनल से चलते हैं, और डिफ़ॉल्ट रूप से एक **ड्राई रन** होते हैं — ये आपको दिखाते हैं कि क्या बैकअप होगा बिना कुछ लिखे, जब तक आप `--execute` न जोड़ें:

```bash
# देखें कि बिना कुछ लिखे बैकअप में क्या शामिल होगा
wolfbot backup --install-root /opt/wolfbot --data-root /var/lib/wolfbot

# असल में बैकअप आर्काइव लिखें
wolfbot backup --install-root /opt/wolfbot --data-root /var/lib/wolfbot --execute
```

बाद में पहचानने लायक नाम से बैकअप टैग करने के लिए `--label "before-weekend"` जोड़ें। नतीजे में मिला आर्काइव प्रतिबंधित फ़ाइल अनुमतियों (सिर्फ़ आपके अपने यूज़र अकाउंट से पढ़ने योग्य) के साथ, इसमें क्या है यह बताने वाली एक रसीद के साथ लिखा जाता है।

> विकल्पों की पूरी, वर्तमान सूची के लिए `wolfbot backup --help` चलाएं — फ़्लैग रिलीज़ के बीच बदल सकते हैं।

### Windows

Windows पर अभी तक कोई समर्पित बैकअप कमांड उपलब्ध नहीं है — फ़िलहाल, सबसे सुरक्षित विकल्प यह है कि किसी बड़े बदलाव से पहले अपना WolfBot डेटा फ़ोल्डर कहीं सुरक्षित जगह कॉपी कर लें (अगर आपको पक्का न हो कि वह कहां है, तो [समस्या निवारण](/docs/troubleshooting) देखें)।

---

## बैकअप से रीस्टोर करें

```bash
wolfbot restore-backup --install-root /opt/wolfbot --data-root /var/lib/wolfbot --backup <path-to-archive>
```

बैकअप की तरह, यह डिफ़ॉल्ट रूप से एक ड्राई रन है ताकि `--execute` से कमिट करने से पहले आप देख सकें कि क्या बदलेगा। अगर आप सिर्फ़ यह जांचना चाहते हैं कि किसी आर्काइव में क्या है, बिना कुछ रीस्टोर किए, तो पहले `wolfbot inspect-backup <path-to-archive>` इस्तेमाल करें।

---

## क्या बैकअप होता है

आपका कॉन्फ़िगरेशन, स्ट्रेटेजी सेटिंग्स, रिस्क पैरामीटर, और ट्रेडिंग हिस्ट्री WolfBot की डेटा डायरेक्टरी में रहती हैं और बैकअप में शामिल होती हैं। ब्रोकर API सीक्रेट सावधानी से संभाले जाते हैं — अगर आपको मशीन माइग्रेशन के लिए भरोसा करने से पहले यह पुष्टि करनी हो कि कोई खास रिलीज़ ठीक-ठीक क्या शामिल करती है, तो `wolfbot backup` का आउटपुट जांचें (ड्राई-रन में भी)।

---

## एक नई मशीन पर माइग्रेट करना

1. पुरानी मशीन पर एक बैकअप बनाएं (`wolfbot backup ... --execute`)
2. नतीजे में मिले आर्काइव को नई मशीन पर कॉपी करें
3. नई मशीन पर WolfBot Community इंस्टॉल करें
4. आर्काइव रीस्टोर करें (`wolfbot restore-backup ...`), फिर अपने अकाउंट और सेटिंग्स वेरिफ़ाई करें — जो API कुंजियां साथ नहीं आईं उन्हें फिर से डालें

## समस्या निवारण

| समस्या | समाधान |
|---|---|
| "Backup creation failed" | डिस्क स्पेस जांचें और यह कि `--install-root`/`--data-root` आपके असली WolfBot पथों की ओर इशारा करते हैं |
| संस्करण बदलने के बाद रीस्टोर गलत दिखता है | पहले WolfBot को उसी संस्करण पर अपडेट करें जिस पर बैकअप लिया गया था, फिर फिर से कोशिश करें |
| पक्का नहीं कि बैकअप सफल हुआ | ज़रूरत पड़ने से पहले इसकी सामग्री जांचने के लिए `wolfbot inspect-backup <path>` चलाएं |
