# सेल्फ-होस्टेड ट्रेडिंग प्लेटफ़ॉर्म समझाया गया

**टेस्ट किया गया संस्करण: WolfBot Community v0.1.0-p12-ghcr-rc19** · आखिरी अपडेट: 2026-08-15

## "सेल्फ-होस्टेड" का क्या मतलब है?

एक सेल्फ-होस्टेड ट्रेडिंग प्लेटफ़ॉर्म **आपके** कंप्यूटर पर चलता है — आपका Windows PC, Linux मशीन, या VPS। आप इसे इंस्टॉल करते हैं, आप इसे कॉन्फ़िगर करते हैं, आप इसे नियंत्रित करते हैं। आपके सारे मार्केट, आपकी सारी स्ट्रेटेजी, आपका सारा डेटा — आपके नियंत्रण में।

```text
क्लाउड-होस्टेड:
आपका ब्राउज़र → किसी और का सर्वर → एक्सचेंज

सेल्फ-होस्टेड (WolfBot Community):
आपकी मशीन → एक्सचेंज (सीधे)
```

---

## सेल्फ-होस्ट क्यों करें?

### 1. पूरा नियंत्रण
- आपकी मशीन, आपके नियम
- कोई तीसरा पक्ष आपकी ट्रेडिंग को रोक नहीं सकता
- आप तय करते हैं कब अपडेट करना है
- कोई सेवा आपके लिए बंद नहीं की जा सकती

### 2. प्राइवेसी
- API कुंजियां आपकी मशीन पर रहती हैं
- ट्रेडिंग डेटा लोकल रहता है
- कोई क्लाउड डेटाबेस आपकी स्ट्रेटेजी स्टोर नहीं करता
- कोई तीसरा पक्ष आपकी पोज़िशन नहीं देखता — किसी भी मार्केट पर

### 3. ज़ीरो कॉस्ट
- WolfBot Community पूरी तरह मुफ़्त है
- कोई सब्सक्रिप्शन फीस नहीं
- कोई प्रति-ट्रेड फीस नहीं
- सिर्फ़ आपकी अपनी बिजली/इंटरनेट की लागत
- सभी मार्केट कवर करने वाला एक प्लेटफ़ॉर्म — क्रिप्टो, फ्यूचर्स, और MT5

### 4. सुरक्षा
- नॉन-कस्टोडियल: कोई तीसरा पक्ष आपके फंड होल्ड नहीं करता
- ट्रेड-ओनली API कुंजियां: विड्रॉल असंभव है
- आपका फ़ायरवॉल, आपके सुरक्षा नियम
- कोई शेयर्ड इंफ्रास्ट्रक्चर अटैक सरफ़ेस नहीं

### 5. कस्टमाइज़ेबिलिटी
- सभी फीचर तक पूरी पहुंच
- सभी कनेक्टेड मार्केट पर कस्टम स्ट्रेटेजी चलाएं
- अपने खुद के टूल के साथ इंटीग्रेट करें
- अपने वर्कफ़्लो के हिसाब से संशोधित करें

## आम चिंताएं

### "क्या मुझे सर्वर चाहिए?"
नहीं। WolfBot Community एक सामान्य Windows या Linux PC पर ठीक चलता है। एक [VPS सिर्फ़ तभी ज़रूरी है जब आप अपना PC ऑन रखे बिना 24/7 ट्रेडिंग चाहते हैं](/docs/run-24-7-on-a-vps)। यह किसी भी एनवायरनमेंट से क्रिप्टो एक्सचेंज और MT5 ब्रोकर दोनों को समान रूप से संभालता है।

### "अगर मेरा PC क्रैश हो जाए तो?"
आपकी पोज़िशन एक्सचेंज पर हैं, आपके PC पर नहीं। WolfBot Community नॉन-कस्टोडियल है। जब आप रीस्टार्ट करते हैं, यह आपकी पोज़िशन अपने आप रिकवर कर लेता है — चाहे वे क्रिप्टो पेयर हों या MT5 इंस्ट्रूमेंट।

### "क्या यह सुरक्षित है?"
हां — कई मायनों में क्लाउड सॉल्यूशन से ज़्यादा सुरक्षित। आपकी API कुंजियां आपकी मशीन से कभी बाहर नहीं जातीं। आप नेटवर्क एक्सेस नियंत्रित करते हैं। ट्रेड-ओनली API कुंजियां किसी को एक्सेस मिलने पर भी विड्रॉल रोकती हैं।

### "अगर मैं तकनीकी नहीं हूं तो भी क्या मैं इसे इस्तेमाल कर सकता हूं?"
हां। Windows इंस्टॉलर एक सामान्य सेटअप विज़ार्ड है — डबल-क्लिक करें, इंस्टॉल करें, खोलें। Linux एक सामान्य .deb पैकेज इस्तेमाल करता है। कोई कोडिंग या Docker अनुभव ज़रूरी नहीं।

## क्या सेल्फ-होस्टिंग आपके लिए सही है?

### ✅ सेल्फ-होस्टिंग अच्छी है अगर आप:
- लागत ज़ीरो रखना चाहते हैं
- अपने खुद के इंफ्रास्ट्रक्चर को नियंत्रित करना पसंद करते हैं
- प्राइवेसी और डेटा ओनरशिप को महत्व देते हैं
- ऐसा कंप्यूटर रखते हैं जो ऑन रह सके (या VPS)
- बेसिक कंप्यूटर सेटअप के साथ सहज हैं

### ❌ क्लाउड बेहतर हो सकता है अगर आप:
- कोई इंफ्रास्ट्रक्चर मैनेज नहीं करना चाहते
- गारंटीड 24/7 अपटाइम चाहिए
- डायरेक्ट सपोर्ट पसंद करते हैं
- एक पूरी तरह मैनेज्ड अनुभव चाहते हैं
