# VPS पर WolfBot Community को 24/7 चलाएँ

**टेस्ट किया गया संस्करण: WolfBot Community v0.1.0-p12-ghcr-rc20** · आखिरी अपडेट: 2026-08-15 · Ubuntu 22.04 / 24.04

## यह गाइड किसके लिए है

दो तरह के पाठकों को यहाँ फायदा मिलता है:

- **अगर आप बस अपने बॉट्स को चौबीसों घंटे चलाना चाहते हैं** — ताकि आपका कंप्यूटर बंद
  होने पर भी कोई ट्रेड छूटे नहीं — तो नीचे दिए चरणों को क्रम से पूरा करें। हर कमांड
  कॉपी-पेस्ट है, और नतीजा पाने के लिए आपको मशीनरी समझने की ज़रूरत नहीं है।
- **अगर आप सर्वर से सहज हैं** और जानना चाहते हैं कि हर चरण इसी तरह *क्यों* किया जाता
  है (केवल-लूपबैक डैशबोर्ड, SSH टनल), तो नोट्स आपके रास्ते में आए बिना वजह समझाते
  हैं।

संक्षेप में: यह गाइड आपके WolfBot Community को एक छोटे हमेशा-चालू Linux सर्वर (VPS)
पर रखती है ताकि वह रात भर ट्रेड करता रहे — आपकी रणनीतियाँ, सेटिंग्स और अकाउंट जैसे
के तैसे रहते हैं, और आपका निजी कंप्यूटर बंद होने पर भी आपके बॉट काम करते रहते हैं।

## आपको क्या चाहिए

- एक Ubuntu 22.04 LTS या 24.04 LTS VPS (कोई भी मुख्यधारा प्रोवाइडर चलेगा — Hetzner,
  DigitalOcean, Vultr, Linode, AWS Lightsail, आदि)
- कम से कम 4 GB RAM और 4 GB डिस्क स्पेस
- टर्मिनल खोलकर अपने सर्वर में SSH करने की क्षमता
- 15 मिनट

> ℹ️ WolfBot Community Docker में चलता है। इंस्टॉलर आपके लिए Docker अपने आप सेट कर
> देता है, बिल्कुल डेस्कटॉप Linux इंस्टॉल की तरह।

## चरण 1: अपना VPS लें और कनेक्ट करें

1. कम से कम 4 GB RAM वाला Ubuntu 22.04/24.04 सर्वर बनाएँ
2. SSH से कनेक्ट करें (ज़्यादातर प्रोवाइडर यह कमांड अपने पेज पर देते हैं):

```bash
ssh your-user@your-server-ip
```

## चरण 2: WolfBot Community इंस्टॉल करें (डेस्कटॉप जैसा ही)

ठीक [Linux इंस्टॉल गाइड](/install/linux) का पालन करें — सर्वर पर चरण बिल्कुल एक जैसे
हैं:

1. [community.wolfbot.io/download](https://community.wolfbot.io/download) से `.deb`
   डाउनलोड करें
2. इसे इंस्टॉल करें (हेडलेस सर्वर पर आप टर्मिनल वाला रूप इस्तेमाल करेंगे):

```bash
sudo apt install ./WolfBot-Setup-linux-amd64.deb
```

3. WolfBot शुरू करें और जाँचें कि यह स्वस्थ है:

```bash
wolfbot start
wolfbot status
```

## चरण 3: डैशबोर्ड तक सुरक्षित पहुँचें (SSH टनल)

WolfBot Community अपने डैशबोर्ड को सिर्फ़ आपके सर्वर के **लूपबैक पते
(127.0.0.1)** पर बाइंड करता है — यह जानबूझकर है: इसका मतलब है कि ट्रेडिंग डैशबोर्ड
डिफ़ॉल्ट रूप से कभी सार्वजनिक इंटरनेट पर खुला नहीं रहता। घर के अपने कंप्यूटर पर,
ब्राउज़र उसे सीधे खोल देता है। VPS पर, आप उस तक एक एन्क्रिप्टेड SSH टनल के ज़रिए
पहुँचते हैं:

```bash
ssh -L 8080:127.0.0.1:8080 your-user@your-server-ip
```

फिर अपने ब्राउज़र में **http://localhost:8080** खोलें। टनल आपके लोकल पोर्ट 8080 को
SSH के ऊपर से सर्वर के डैशबोर्ड तक फॉरवर्ड करती है — कोई खुला पोर्ट नहीं, कोई सार्वजनिक
URL नहीं, फ़ायरवॉल के लिए कुछ भी नहीं।

> 🔎 **तकनीकी पाठकों के लिए:** WolfBot Community की सेवाएँ डिज़ाइन से `127.0.0.1`
> (लूपबैक) पर बाइंड होती हैं — control-api `8765` पर, gateway `8766` पर, और डैशबोर्ड
> `8080` पर। केवल-लूपबैक का मतलब है कि ट्रेडिंग सतह इंटरनेट से कभी नहीं पहुँची जा
> सकती, इसलिए सार्वजनिक पोर्ट खोलने की जगह SSH टनल उस तक दूर से पहुँचने का सही (और
> सबसे सरल) तरीका है।

> ⚠️ डैशबोर्ड को सार्वजनिक इंटरनेट पर **कभी** न खोलें। उसे लूपबैक पर रखें और SSH टनल
> इस्तेमाल करें। डैशबोर्ड असली ट्रेडिंग को नियंत्रित करता है, इसलिए उसे निजी रहना
> चाहिए।

## चरण 4: सर्वर पर बैकअप लें

आपकी कॉन्फ़िगरेशन अब आपके VPS पर रहती है, इसलिए वहीं बैकअप लें:

```bash
wolfbot backup --install-root /opt/wolfbot --data-root /var/lib/wolfbot --execute
```

फिर सुरक्षित रखने के लिए आर्काइव को सर्वर से बाहर कॉपी करें। पूरी प्रक्रिया के लिए
[बैकअप और रिस्टोर गाइड](/docs/backup) देखें।

## चरण 5: इसे अपडेट रखें

सर्वर पर, अपडेट साइन किए गए अपडेटर के ज़रिए चलते हैं:

```bash
/opt/wolfbot/launcher/wolfbot-updater.sh check
```

apply/rollback चरणों के लिए [अपडेट गाइड](/docs/updates) देखें।

## अपेक्षित नतीजा

- WolfBot Community आपके PC से स्वतंत्र, आपके VPS पर Docker में चलता है
- आप SSH टनल के ज़रिए डैशबोर्ड तक पहुँचते हैं (केवल-लूपबैक, कोई सार्वजनिक पोर्ट नहीं)
- आपका कंप्यूटर बंद होने पर भी बॉट ट्रेड करते रहते हैं और रणनीतियाँ चलती रहती हैं

## आम गलतियाँ

| गलती | सुधार |
|---|---|
| डैशबोर्ड को सार्वजनिक इंटरनेट पर खोलना | ऐसा न करें — SSH टनल इस्तेमाल करें, केवल-लूपबैक रखें |
| सर्वर पर बैकअप लेना भूल जाना | `wolfbot backup ... --execute`, फिर आर्काइव को बॉक्स से बाहर कॉपी करें |
| सर्वर रीबूट हो और WolfBot न चल रहा हो | `wolfbot status` से पुष्टि करें; ज़रूरत हो तो `wolfbot start` |
| लैपटॉप सोने पर टनल टूट जाए | `ssh -L ...` कमांड दोबारा चलाएँ; यह एक सामान्य रीकनेक्ट है |

## समस्या निवारण

- **टनल से localhost:8080 तक नहीं पहुँच पा रहे** — पुष्टि करें कि टनल कमांड अब भी
  चल रही है और `wolfbot status` सेवाओं को स्वस्थ दिखा रहा है।
- **SSH connection refused** — जाँचें कि आपके VPS का फ़ायरवॉल SSH (पोर्ट 22) की अनुमति
  देता है और आप सही user/IP इस्तेमाल कर रहे हैं।
- अन्य समस्याएँ — पूरी [समस्या निवारण गाइड](/docs/troubleshooting) देखें।
