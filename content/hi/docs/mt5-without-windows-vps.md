# बिना Windows VPS के MT5 चलाएं

**टेस्ट किया गया संस्करण: WolfBot Community v0.1.0-beta.2** · आखिरी अपडेट: 2026-08-15

## यह गाइड किसके लिए है

- **अगर आप Forex, Gold, Indices या Stocks/CFDs ट्रेड करते हैं और Windows सर्वर किराए पर नहीं लेना चाहते** — यह साफ़ भाषा में समझाता है कि आप Linux पर MT5 कैसे चलाते हैं और इससे क्या बचता है।
- **अगर आप तकनीकी रूप से इच्छुक हैं** — आप देखेंगे कि Linux MT5 ब्रिज कैसे कंटेनराइज़्ड है और कोई रिमोट-डेस्कटॉप क्लाइंट क्यों ज़रूरी नहीं।

## जो समस्या MT5 आमतौर पर बनाता है

MetaTrader 5 एक Windows एप्लिकेशन है। अगर आप इसके ज़रिए Forex, Gold, Indices या Stocks/CFDs ऑटोमेट करना चाहते हैं, तो पारंपरिक रास्ता है: एक Windows VPS किराए पर लें, उस पर MT5 इंस्टॉल करें, इसे 24/7 चलाए रखें, और अब आप सिर्फ़ एक टर्मिनल ज़िंदा रखने के लिए पूरी दूसरी मशीन के लिए भुगतान और रखरखाव कर रहे हैं — इसके ऊपर जो भी आप पहले से अपना ट्रेडिंग बॉट चला रहे हैं।

यही मान्यता ज़्यादातर सेल्फ-होस्टेड ट्रेडिंग टूल छोड़ देते हैं। WolfBot Community नहीं।

## WolfBot Community असल में Linux पर MT5 कैसे चलाता है

आपसे अपना खुद का Windows एनवायरनमेंट लाने को कहने के बजाय, WolfBot Community आपके Linux इंस्टॉल में **पहले से बना हुआ** MT5 सपोर्ट शिप करता है: एक असली MetaTrader 5 टर्मिनल, WolfBot के बाकी हिस्से जैसी ही मशीन पर एक Docker कंटेनर के अंदर चलता है — एक कमांड से एक्टिवेट किया जाता है, और आपके अपने ब्राउज़र से नियंत्रित होता है, किसी रिमोट डेस्कटॉप क्लाइंट से नहीं।

```text
आपकी Linux मशीन (या Linux VPS)
    │
    ├── WolfBot Community — बाकी प्लेटफ़ॉर्म
    │
    └── MT5 ब्रिज कंटेनर
            ├── एक असली MT5 टर्मिनल, हेडलेस चल रहा है
            └── इसमें एक ब्राउज़र विंडो (कोई VNC क्लाइंट इंस्टॉल करने की ज़रूरत नहीं)
```

इसे चालू करना एक कमांड है (सटीक सिंटैक्स के लिए [MT5 कनेक्ट गाइड](/brokers/mt5#for-technical-users) देखें), जिसके बाद आप अपने ब्राउज़र में एक URL खोलते हैं, ठीक वैसे ही अपने ब्रोकर में लॉग इन करते हैं जैसे आप Windows डेस्कटॉप पर करते, और WolfBot का ब्रिज उस टर्मिनल से सीधे बात करता है।

## व्यवहार में इसका क्या मतलब है

- **कोई दूसरी मशीन नहीं।** एक Linux बॉक्स आपके क्रिप्टो अकाउंट, आपका MT5 अकाउंट, और WolfBot खुद चलाता है।
- **कोई RDP नहीं, कोई रिमोट डेस्कटॉप सॉफ़्टवेयर नहीं।** टर्मिनल आपके मौजूदा ब्राउज़र में एक पेज के रूप में खुलता है।
- **कोई Windows लाइसेंसिंग नहीं, कोई Windows VPS बिल नहीं।** अगर आप WolfBot को 24/7 चलाने के लिए पहले से Linux VPS का भुगतान कर रहे हैं, तो MT5 उसी बॉक्स पर मुफ़्त में साथ चलता है।
- **वही रिस्क इंजन, वही स्मार्ट टर्मिनल।** एक बार कनेक्ट होने पर, MT5 अकाउंट WolfBot के अंदर बिल्कुल क्रिप्टो अकाउंट जैसा व्यवहार करता है — वही रिस्क कंट्रोल, वही डेमो/लाइव मॉडल, वही पोर्टफोलियो व्यू।

## क्या यह Windows जैसा ही है?

फ़ंक्शनल रूप से, हां — आपको दोनों तरह से एक असली, पूरी तरह काम करने वाला MT5 टर्मिनल मिलता है। फ़र्क सिर्फ़ इसमें है कि यह *कहां* चलता है: अगर आप पहले से Windows इस्तेमाल कर रहे हैं तो नेटिवली Windows पर, या अगर आप Linux पर हैं तो एक ब्राउज़र-एक्सेसिबल कंटेनर के अंदर। किसी भी रास्ते के लिए दोनों ऑपरेटिंग सिस्टम रखने की ज़रूरत नहीं है।
