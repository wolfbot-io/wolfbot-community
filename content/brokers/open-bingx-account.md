# How to Open a BingX Account with WolfBot

**[Open the WolfBot BingX registration page →](https://bingxdao.com/partner/Wolfbot/)**

> The link may redirect. Continue only when the final page uses HTTPS and an official BingX domain. Referral attribution goes to WolfBot; BingX alone determines any promotion.

![Four-step BingX account-opening flow: referral, registration, KYC, and authenticator 2FA](/images/guides/open-bingx-account.png)

*Instructional diagram, not a BingX UI screenshot.*

## Prepare

Use a personal email protected by 2FA, a unique password, password manager, authenticator app, camera phone, and eligible unexpired document. Check regional rules inside BingX; do not use a VPN or false address.

## Step 1: open the referral safely

1. Open the WolfBot link and watch the redirect destination.
2. Confirm the final hostname belongs to BingX; close any browser certificate warning.
3. Select your true country/region and enter data only on the official site.

## Step 2: create the account

1. Select email or phone and enter contact information you control.
2. Receive and enter the verification code in the same registration session.
3. Create a unique password and store it in a password manager.
4. Sign in again and review login alerts/activity.

## Step 3: complete the appropriate KYC

1. Web: profile icon → **Identity Verification → Individual Verification**. App: avatar → **Verification**.
2. If **Basic Verification** is shown, select Verify Now, enter truthful details, and submit.
3. For **Advanced Verification**, select issuing country/document type, capture the whole document clearly, and complete the requested selfie.
4. Ensure form and document information match; use bright, unedited images with every corner visible.
5. Review the result inside the account. KYC-level benefits and limits can vary by region, so rely on the values BingX shows you.

## Step 4: enable 2FA and anti-phishing protection

1. Open Security and link an authenticator app.
2. Save the setup/recovery key offline before confirming the six-digit code.
3. Enable anti-phishing code, withdrawal whitelist, and device alerts when available.
4. Remove unknown sessions, test sign-out/sign-in, and never share OTP/2FA codes.

## Step 5: prepare WolfBot

- [ ] Required KYC and 2FA complete.
- [ ] Recovery key stored separately from the password.
- [ ] [Trade-only API guide](/brokers/api-key-guide) reviewed.
- [ ] New WolfBot-only API key planned; **Withdrawal/Transfer disabled**.

Continue with [Connect BingX to WolfBot](/brokers/bingx), then use [Simulation](/docs/simulation) and [Risk Controls](/docs/risk-controls). If Connect Account does not show the correct path for your account type, do not guess API permissions—follow the guide shipped with the release.

## Troubleshooting

| Problem | Action |
|---|---|
| Referral ends on an unfamiliar domain | Close it, reopen this article's link, and verify the BingX domain. |
| KYC fails | Check issuing country/type, image corners, lighting, and matching details. |
| Code missing | Check spam/country code and wait for the resend timer. |
| 2FA lost | Use recovery or the official process; never send documents to chat accounts. |
