# Community vs Cloud

**어떤 WolfBot이 나에게 맞을까요?**

두 에디션은 동일한 통합 거래 엔진을 공유합니다. 암호화폐 + 선물 + MT5 — 하나의 플랫폼, 모든 시장.

---

## 한눈에 보기

| | WolfBot Community | WolfBot Cloud |
|---|---|---|
| **비용** | 무료 | 구독 |
| **호스팅** | 내 기기 | WolfBot.io 관리 |
| **설정** | 설치 및 구성 | 몇 분 내 준비 |
| **업데이트** | 채널 기반 자동 업데이트 | 자동 |
| **인프라** | 내가 관리 | 우리가 관리 |
| **지원** | 커뮤니티 (Discussions) | 직접 지원 |
| **커스터마이징** | 전체 접근 | 플랫폼 내 |
| **가동 시간** | 내 책임 | 24/7 관리 |

---

## WolfBot Community

### 가장 적합한 경우:
- 인프라를 완전히 통제하려는 트레이더
- 셀프 호스팅에 익숙한 기술 사용자
- WolfBot을 무료로 테스트하려는 분 — 암호화폐와 MT5를 위한 하나의 플랫폼
- 개인 PC 또는 VPS에서 운영
- 비용을 중시하는 트레이더

### 내가 책임지는 것:
- 소프트웨어 설치
- 기기 가동 유지
- 백업 관리
- 네트워크/방화벽 구성
- 업데이트 적용 (원클릭이지만 수동)

### 주요 장점:
- ✅ 완전 무료
- ✅ 데이터가 내 기기에 보관
- ✅ 구독 의무 없음
- ✅ Cloud와 동일한 거래 엔진 — 암호화폐 + 선물 + MT5
- ✅ 전체 API 접근
- ✅ GitHub를 통한 오픈 개발

---

## WolfBot Cloud

### 가장 적합한 경우:
- 관리형, 유지보수 불필요 경험을 원하는 트레이더
- 서버를 관리하고 싶지 않은 분
- PC/VPS 관리 없이 24/7 거래
- 우선 지원 필요
- 팀 및 다중 계정 관리

### WolfBot.io가 처리하는 것:
- 서버 호스팅 및 가동 시간
- 인프라 유지보수
- 자동 업데이트
- 백업 및 재해 복구
- 보안 모니터링
- 성능 최적화

### 주요 장점:
- ✅ 설치 불필요
- ✅ 항상 온라인 — 24/7 운영
- ✅ 팀의 직접 지원
- ✅ 모든 것이 자동
- ✅ 다중 계정 대시보드
- ✅ 고급 분석

## 일반적인 전환 경로

### Community 시작 → Cloud로

많은 사용자가 Community로 시작합니다:
1. WolfBot을 무료로 위험 없이 테스트 (무료, 데모 계정)
2. 암호화폐 및 MT5 시장에서 전략 검증
3. 통합 인터페이스에 익숙해지기
4. 관리형 24/7 거래 준비가 되면 Cloud로 전환

### Cloud → Community

Cloud 사용자가 Community를 사용하는 경우:
- 개발 및 테스트
- 로컬에서 자체 전략 실행
- 백업 거래 환경
- 개인정보 보호가 중요한 작업

## 둘 다 사용할 수 있나요?

네! 둘 다 운영할 수 있습니다:

- **Community**는 테스트/개발용 PC에서
- **Cloud**는 24/7 프로덕션 거래용

별도의 설치이며 서로 간섭하지 않습니다.

## 자주 묻는 질문

**Q: Community가 Cloud의 "제한된" 버전인가요?**
아니요. Community는 동일한 거래 엔진, 전략, 브로커 지원을 갖습니다. 동일한 통합 플랫폼 — 암호화폐, 선물, MT5. 차이는 호스팅과 지원입니다.

**Q: Community는 항상 무료인가요?**
네. WolfBot Community는 모두를 위한 무료 셀프 호스팅 통합 거래 플랫폼을 제공하겠다는 약속입니다.

**Q: Community에서 Cloud로 마이그레이션할 수 있나요?**
네. 구성을 내보내고 전략을 내보내면 팀이 전환을 돕습니다.

**Q: Cloud에 Community에 없는 기능이 있나요?**
Cloud에는 관리형 호스팅, 팀 기능, 고급 분석, 직접 지원이 포함됩니다. 모든 시장 지원을 포함한 핵심 거래 엔진은 동일합니다.
