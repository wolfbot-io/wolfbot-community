# 커뮤니티 상태

**WolfBot Community v0.1.0-beta.9에서 테스트됨** · 마지막 업데이트: 2026-08-15

## 현재 상태

WolfBot Community의 현재 공개 릴리스 트랙은 **v0.1.0-beta.9**입니다.

| 영역 | 상태 |
|---|---|
| **현재 버전** | v0.1.0-beta.9 |
| **Windows** | ✅ 사용 가능 |
| **Linux** | ✅ 사용 가능 |
| **암호화폐 거래** | ✅ 사용 가능 |
| **선물 거래** | ✅ 사용 가능 |
| **MT5 거래** | ✅ 사용 가능 |
| **문서** | ✅ 이 사이트에 라이브 |

## 지원 플랫폼

| 플랫폼 | 상태 | 비고 |
|---|---|---|
| **Windows** | ✅ | 설치 프로그램 사용 가능 |
| **Linux** | ✅ | 설치 프로그램 & Docker 사용 가능 |
| **macOS** | ⏳ | 진행 중 |

---

## 작동하는 것

- ✅ 통합 거래 플랫폼 — 하나의 인터페이스에서 암호화폐, 선물, MT5
- ✅ 모든 시장에서 수동 거래를 위한 Smart Terminal
- ✅ 리스크 관리 (포지션 한도, 드로다운 보호, 쿨다운)
- ✅ 위험 없는 테스트를 위한 데모/테스트넷 계정
- ✅ 다중 브로커 연결 (Binance, Bybit, BingX, KuCoin, Bitget + MT5)
- ✅ 롤백이 있는 자동 업데이트
- ✅ CLI를 통한 백업 & 복원

## 기여 방법

WolfBot Community는 오픈 개발입니다:

1. **소프트웨어 사용** — 설치하고 테스트
2. **문제 보고** — 세부 정보로 이슈 작성
3. **피드백 공유** — 토론 참여
4. **널리 알리기** — 다른 트레이더에게 소개
5. **번역 기여** — 번역 도움 (문의)
