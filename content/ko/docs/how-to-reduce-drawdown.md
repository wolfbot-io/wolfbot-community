# 거래 드로다운을 줄이는 방법

**WolfBot Community v0.1.0-beta.9에서 테스트됨** · 마지막 업데이트: 2026-08-15

## 드로다운이란?

드로다운은 고점에서 저점까지의 계정 하락입니다. 겪은 **최악의 손실 구간**을 측정합니다.

```text
$10.000 → $15.000 (고점) → $11.000 (저점)
드로다운 = (15.000 - 11.000) / 15.000 = 26,7%
```

드로다운이 낮을수록 더 침착하게 거래할 수 있고 — 불가피한 손실 구간을 견딜 가능성도 높아집니다.

## 이 가이드의 대상

- **모든 트레이더:** 통계학 공부 없이 드로다운을 낮추는 여섯 가지 실행 가능한 단계.
- **기술 사용자:** 그 뒤의 수학과 WolfBot이 이 규칙을 자동으로 강제하는 방법.

## 낮은 드로다운이 중요한 이유

| 드로다운 | 필요한 회복 | 감정적 압박 |
|---|---|---|
| 10% | 11% 이익 | 낮음 |
| 25% | 33% 이익 | 뚜렷함 |
| 50% | 100% 이익 | 높음 |
| 75% | 300% 이익 | 극심 |

더 깊이 빠질수록 회복이 더 어려워지고 — **그리고** 감정적으로 포기할 가능성도 높아집니다.

## 드로다운을 낮추는 여섯 단계

### 1. 포지션 크기 제한

드로다운 통제의 가장 효과적인 수단.

**규칙:** 단일 거래에서 계정의 1–2% 이상을 위험에 빠뜨리지 마세요.

```text
계정 $10.000 → 거래당 위험 = $100–$200
```

- 2% 위험 시: 연속 10번 손실이어도 = -20% (아프지만 견딜 수 있음)
- 10% 위험 시: 연속 10번 손실 = 거의 파산

**WolfBot에서:** `Max position % of balance`를 2–5%로 설정.

### 2. 모든 포지션에 스톱로스 사용

스톱로스는 단일 거래의 손실을 알려진 금액으로 제한합니다.

**WolfBot에서:** Smart Terminal이 모든 포지션에 기본으로 스톱로스를 설정합니다. 절대 제거하지 마세요.

### 3. 시장 전반에 다각화

한 시장에 모든 것을 걸지 마세요. WolfBot은 암호화폐 **및** MT5(외환, 금, 지수)를 거래합니다 — 상관관계가 낮은 상품에 위험을 분산하세요.

**도움이 되는 이유:** 한 시장이 하락하면 다른 시장이 상승해 전체 드로다운을 완화할 수 있습니다.

### 4. 손실 후 쿨다운 사용

손실 거래 후 감정적 결정 가능성이 높습니다. 휴식을 강제하세요.

**WolfBot에서:** `After loss cooldown`을 5–15분으로 설정.

### 5. 일일 손실 한도 설정

거래가 중단되는 최대 일일 손실을 정하세요.

**WolfBot에서:** `Daily loss limit`을 5–10%로 설정. 이후 거래가 자동으로 일시 중지됩니다.

### 6. 레버리지 감소

레버리지는 이익 **그리고** 손실을 증폭합니다.

| 레버리지 | 가격 움직임 | 계정 영향 |
|---|---|---|
| 1x | 10% | 10% |
| 5x | 10% | 50% |
| 10x | 10% | 100% (파산) |

**WolfBot에서:** `Max leverage`를 보수적으로 설정 (초보자는 1x–3x).

## 회복의 수학

손실 후 원점으로 돌아가려면 더 많은 이익이 필요합니다:

```text
손실 10% → 손익분기까지 +11% 필요
손실 20% → +25% 필요
손실 30% → +43% 필요
손실 50% → +100% 필요
```

드로다운이 깊을수록 회복 곡선이 가팔라집니다 — 드로다운을 작게 유지해야 하는 또 다른 이유.

## 전/후 예시

### 전 (높은 드로다운)

```
포지션: 계정의 20%
레버리지: 10x
스톱: 자주 무시
손실: 휴식 없음
결과: 나쁜 구간에서 60% 드로다운
```

### 후 (낮은 드로다운)

```
포지션: 계정의 3%
레버리지: 2x
스톱: 항상 설정
손실: 10분 쿨다운
결과: 같은 구간에서 15% 드로다운
```

같은 전략, 같은 시장 환경 — 완전히 다른 위험 프로필.

## WolfBot에서 구현

이 가이드의 모든 것은 WolfBot의 리스크 관리에서 구성할 수 있습니다:

| 단계 | WolfBot 설정 |
|---|---|
| 포지션 크기 | `Max position %` |
| 스톱로스 | Smart Terminal (기본) |
| 다각화 | 여러 브로커/시장 연결 |
| 쿨다운 | `After loss cooldown` |
| 일일 한도 | `Daily loss limit` |
| 레버리지 | `Max leverage` |

> 전체 안내는 [리스크 관리 가이드 →](/docs/risk-controls) 참조

## 생각해볼 점

드로다운은 불가피하지만 — 그 **크기**는 내 손에 있습니다. 포기하는 대부분의 트레이더는 전략 때문이 아니라 견디기에 너무 큰 드로다운 때문에 포기합니다.
