# 리스크 관리 가이드

**WolfBot Community v0.1.0-p12-ghcr-rc21에서 테스트됨** · 마지막 업데이트: 2026-08-15

## 리스크 관리가 중요한 이유

리스크 관리는 거래 환경 전체에 걸친 안전망 역할을 합니다 — 과도한 거래를 방지하고, 손실을 제한하며, Binance에서 암호화폐를 거래하든 Bybit에서 선물을, MT5로 금을 거래하든 계정을 보호합니다. 어떤 시장에서 거래하든 동일한 리스크 규칙이 일관되게 적용됩니다.

> 🛡️ 리스크 관리는 데모와 실계정에서 동일하게 활성화됩니다. 거래 시작 전에 구성하세요.

## 리스크 관리 수준

WolfBot에는 네 가지 리스크 보호 수준이 있습니다 — 모든 연결 시장에 동일하게 적용됩니다:

| 수준 | 기능 | 예시 |
|---|---|---|
| **Position Size** | 개별 거래 크기 제한 | 거래당 잔액의 최대 5% |
| **Drawdown Guard** | 손실 임계값 후 거래 중단 | 일일 손실 10% 초과 시 일시 중지 |
| **Cooldown Timer** | 거래 간 최소 시간 | 주문 간 최소 60초 |
| **Daily Limits** | 하루 최대 거래 수 | 24시간당 최대 20회 |

---

## 1. 포지션 크기 한도

단일 거래가 너무 많은 자본을 위험에 빠뜨리는 것을 방지 — 암호화폐 쌍과 MT5 상품에 동일하게 적용됩니다.

### 설정

1. 사이드바에서 **Risk**로 이동
2. **Position Sizing** 찾기
3. 구성:

| 설정 | 권장 (초보자) | 설명 |
|---|---|---|
| **Max position % of balance** | 2–5% | 단일 거래 최대 크기 |
| **Total exposure %** | 20–30% | 모든 포지션 합계 |
| **Max leverage** | 1x–3x | 포지션당 레버리지 한도 |

### 예시

잔액이 $10,000이고 최대 포지션이 5%인 경우:
- 최대 단일 거래: **$500**
- 모든 포지션 합계: **$2,000–$3,000**

---

## 2. 드로다운 가드

손실이 임계값을 초과하면 전체 거래를 중단합니다.

### 설정

| 설정 | 권장 | 설명 |
|---|---|---|
| **Daily loss limit** | 5–10% | 하루 거래 중단 |
| **Weekly loss limit** | 15–20% | 주간 거래 중단 |
| **Total drawdown limit** | 25–30% | 수동 재활성화 필요 |

### 동작

트리거되면:
1. 모든 활성 봇 일시 중지
2. 새 주문 거부
3. 기존 포지션은 계속 관리/청산 가능
4. 대시보드에 알림 표시

> ℹ️ 드로다운 잠금 중에도 포지션을 수동으로 청산할 수 있습니다 — 새 진입만 차단됩니다.

---

## 3. 쿨다운 타이머

빠른 연속 거래와 감정적 결정을 방지합니다.

### 설정

| 설정 | 권장 | 설명 |
|---|---|---|
| **Minimum interval** | 30–120초 | 주문 배치 간 시간 |
| **After loss cooldown** | 5–15분 | 손실 거래 후 추가 대기 |
| **Per-symbol cooldown** | 60초 | 동일 심볼 재진입 지연 |

---

## 4. 일일 거래 한도

하루 거래 수를 제한합니다.

| 설정 | 권장 | 설명 |
|---|---|---|
| **Max trades per day** | 10–20 | 총 주문 수 (모든 심볼) |
| **Max trades per symbol** | 5 | 거래쌍당 주문 수 |

UTC 자정에 재설정됩니다.

## 빠른 시작: 권장 리스크 프로필

### 초보자 (데모 / 첫 실거래)

```
최대 포지션: 잔액의 2%
총 노출: 20%
최대 레버리지: 1x
일일 손실 한도: 5%
쿨다운: 120초
최대 거래/일: 10
```

### 보수적 실거래

```
최대 포지션: 잔액의 3%
총 노출: 25%
최대 레버리지: 2x
일일 손실 한도: 8%
쿨다운: 60초
최대 거래/일: 15
```

### 숙련자

```
최대 포지션: 잔액의 5%
총 노출: 40%
최대 레버리지: 5x
일일 손실 한도: 12%
쿨다운: 30초
최대 거래/일: 30
```

## 비상: 전역 중지

모든 것을 즉시 중지해야 하는 경우:

1. 사이드바에서 **Risk**로 이동
2. **Emergency Stop** 클릭
3. 이는:
   - 모든 봇 일시 중지
   - 모든 미체결 주문 취소
   - 새 진입 거부
   - 기존 포지션은 청산하지 않음 (내가 결정)

## 자주 묻는 질문

**Q: 특정 거래에서 리스크 관리를 무시할 수 있나요?**
리스크 관리는 전역적으로 적용됩니다. 거래 전에 Risk 페이지에서 파라미터를 조정할 수 있습니다.

**Q: 잔액이 변경되면 어떻게 되나요?**
포지션 크기 한도는 현재 잔액에 자동으로 조정됩니다.

**Q: 리스크 관리는 자동 봇에 적용되나요?**
네 — 네 가지 수준 모두 모든 연결 시장의 수동 및 자동 거래에 적용됩니다.

**Q: 리스크 관리를 비활성화할 수 있나요?**
리스크 관리는 조정할 수 있지만 활성 상태를 유지할 것을 강력히 권장합니다. 이것이 주요 안전망입니다.
