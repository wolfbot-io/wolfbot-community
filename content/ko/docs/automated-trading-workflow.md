# 자동 거래 워크플로

**WolfBot Community v0.1.0-p12-ghcr-rc21에서 테스트됨** · 마지막 업데이트: 2026-08-15

## 개요

자동 거래는 소프트웨어가 미리 정한 규칙에 따라 거래를 실행하는 것을 의미합니다 — 계속 화면 앞에 앉아 있을 필요 없이. WolfBot Community는 암호화폐, 선물, MT5(외환, 금, 지수) 등 모든 시장에서 이 규칙을 실행합니다.

## 이 가이드의 대상

- **모든 트레이더:** 첫 봇부터 실거래까지의 명확한 워크플로 — 프로그래밍 지식 불필요.
- **기술 사용자:** 규칙, 리스크 관리, 실행이 WolfBot에서 어떻게 함께 작동하는지 이해.

## 워크플로 개요

```text
1. 전략 선택
   ↓
2. 봇 구성
   ↓
3. 데모 테스트
   ↓
4. 리스크 검토
   ↓
5. 실거래 전환
   ↓
6. 모니터링 및 조정
```

---

## 1단계: 전략 선택

나에게 맞는 거래 접근 방식 선택:

| 전략 | 설명 | 가장 적합 |
|---|---|---|
| **Grid Trading** | 가격 범위에서 저가 매수, 고가 매도 | 횡보 시장 |
| **DCA** | 간격을 두고 매수해 평균 가격 낮춤 | 추세 시장 |
| **추세 추종** | 상승 모멘텀 매수, 하락 매도 | 강한 추세 |
| **TP/SL 자동화** | 자동 이익/손실 목표 | 모든 전략 |

---

## 2단계: 봇 구성

각 봇은 동작을 정의하는 파라미터를 갖습니다. 정확한 파라미터는 전략에 따라 다르지만 기본 패턴은 동일합니다.

### 핵심 파라미터

| 파라미터 | 설명 |
|---|---|
| **심볼** | 거래할 상품 (암호화폐 또는 MT5) |
| **방향** | 롱, 숏 또는 양방향 |
| **포지션 크기** | 각 거래의 크기 (리스크 관리로 제한) |
| **TP/SL** | 이익 및 손실 목표 |
| **진입 규칙** | 거래 개시 시점 |
| **청산 규칙** | 거래 종료 시점 |

### 예시: 간단한 DCA 봇

```
심볼: BTC/USDT
방향: 롱
첫 매수: $100
추가 매수: -5% 가격 하락마다
최대 매수: 5회
테이크프로핏: 평균 가격에서 +3%
스톱로스: -10%
```

## 3단계: 데모 계정에서 테스트

**항상 데모 계정에서 먼저 테스트하세요.**

1. 데모/테스트넷 계정 연결 ([데모 가이드](/docs/simulation) 참조)
2. 봇을 만들어 데모 계정으로 설정
3. 최소 며칠 실행
4. 다양한 시장 상황에서 어떻게 동작하는지 관찰
5. TP/SL이 예상대로 작동하는지 확인

> ⚠️ 데모 계정은 봇의 **메커니즘**을 검증하지, 반드시 **수익성**을 검증하지는 않습니다. 과거 성과가 미래 결과를 보장하지 않습니다.

---

## 4단계: 리스크 검토

실거래 전에 리스크 관리를 확인하세요:

- [ ] 포지션 크기 한도가 보수적임
- [ ] 일일 손실 한도 설정됨
- [ ] 쿨다운 타이머 활성
- [ ] 최대 레버리지 제한됨
- [ ] 모든 거래에 TP/SL 있음

> 전체 안내는 [리스크 관리 가이드 →](/docs/risk-controls) 참조

---

## 5단계: 실거래 전환

준비되면:

1. **Trade-Only** API 키로 실계정 연결
2. **최소** 포지션 크기로 시작
3. 한 번에 하나의 봇 활성화
4. 첫 거래를 면밀히 모니터링
5. 신뢰를 쌓으며 점진적으로 확대

---

## 6단계: 모니터링 및 조정

자동화가 "잊어도 된다"는 의미는 아닙니다.

### 정기 점검

- **매일:** 봇이 실행 중이고 거래가 예상대로 실행되는지 확인
- **매주:** 성과와 드로다운 검토
- **매월:** 전략 가정 검토, 파라미터 조정

### 개입해야 할 때

- 한도를 초과하는 예상치 못한 손실
- 시장 체제 변화 (강한 추세 → 횡보)
- 브로커/MT5 조건 변경
- 위험에 불편함을 느낌

---

## 모범 사례

1. **작게 시작** — 전략이 입증될 때까지 최소 크기
2. **한 번에 하나의 전략** — 과도한 복잡성 피하기
3. **기록 유지** — 무엇을 바꾸고 왜 바꾸는지 기록
4. **규율 유지** — 감정 때문에 규칙에서 벗어나지 않기
5. **리스크 관리 존중** — 안전망입니다

## 흔한 함정

| 함정 | 회피 |
|---|---|
| 너무 크게 시작 | 최소 크기로 시작 |
| 데모 건너뜀 | 항상 데모 먼저 테스트 |
| 리스크 관리 무시 | 먼저 구성 |
| 과도한 거래 | 쿨다운과 일일 한도 설정 |
| 전략 포기 | 입증된 전략에 시간 주기 |
