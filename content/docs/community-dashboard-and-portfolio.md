# One Dashboard for the Whole Trading Operation

WolfBot Community is designed around one operational view, not a collection of disconnected broker tabs. The home screen brings Portfolio, Strategies, Bots, Terminal and Risk Center into one self-hosted workspace, while the Overview separates Demo and Live accounts so the environment is always explicit.

![WolfBot Community home showing the main trading workspace and feature navigation](/images/product/0.1.0-beta.20/en/01-home.webp "The WolfBot Community home screen connects the core workflow without hiding it behind marketing panels.")

## Demo and Live stay visibly separate

The Overview lets you inspect Demo accounts before moving to Live. Account names, balances and performance shown in these screenshots come from the real local Community installation; they are not invented marketing figures. A Live tab is useful for operations, but it is not a promise of returns.

![WolfBot Community Demo overview with connected accounts and performance summary](/images/product/0.1.0-beta.20/en/02-overview-demo.webp "Demo accounts provide a controlled place to verify connectivity, strategy behavior and risk settings.")

![WolfBot Community Live overview showing real connected account information](/images/product/0.1.0-beta.20/en/03-overview-live.webp "The Live overview keeps the production environment clearly labelled.")

## Portfolio is where the accounts become one system

The Portfolio page consolidates equity, account state and open positions. This matters when crypto futures and MT5 positions share the same capital and risk process: an operator needs total exposure, not five partial views.

Use the screen to answer four questions:

1. Which account and environment produced the number?
2. Is equity changing because of closed results, open positions or cash flow?
3. Is risk concentrated in one symbol, direction or venue?
4. Does the portfolio view agree with the broker before you increase exposure?

![WolfBot Community unified portfolio with equity and position information](/images/product/0.1.0-beta.20/en/04-portfolio.webp "Portfolio combines connected account and position information in one inspectable view.")

## Monitor without being tied to the desk

The responsive Overview keeps the key state readable on a phone-sized viewport. It is intended for checking status, not encouraging constant intervention. Strategy changes, broker permissions and risk limits deserve a full review on a trusted computer.

![WolfBot Community Overview on a mobile viewport](/images/product/0.1.0-beta.20/en/36-mobile-overview.webp "The same Overview adapts to a narrow screen for quick operational checks.")

## Jump to a tool without hunting through menus

The command palette provides fast navigation while keeping the full feature map searchable. It is useful for repeated operator workflows, especially as the installation gains more accounts and tools.

![WolfBot Community command palette for quick navigation](/images/product/0.1.0-beta.20/en/08-command-palette.webp "Quick search opens tools and pages without changing trading state.")

## A practical first session

- Connect one Demo account.
- Confirm the balance and environment in Overview.
- Open Portfolio and compare it with the broker.
- Review [Risk Controls](/docs/risk-controls).
- Run a strategy in Simulation before considering Live.

The dashboard is valuable because it shortens the path from observation to evidence. It does not replace broker records or risk discipline; it gives both a coherent operating surface.
