# Community 对比 Cloud

**哪个版本的 WolfBot 更适合你?**

两个版本共享同一个统一交易引擎。加密货币 + 期货 + MT5——一个平台,覆盖每个市场。

---

## 一览对比

| | WolfBot Community | WolfBot Cloud |
|---|---|---|
| **费用** | 免费 | 订阅制 |
| **托管方式** | 你自己的机器 | 由 WolfBot.io 托管 |
| **设置** | 需自行安装配置 | 几分钟内即可就绪 |
| **更新** | 按渠道自动更新 | 全自动 |
| **基础设施** | 由你管理 | 由我们管理 |
| **支持** | 社区(讨论区) | 直接技术支持 |
| **自定义程度** | 完全访问权限 | 平台范围内 |
| **在线时长** | 由你负责 | 24/7 托管保障 |

---

## WolfBot Community

### 最适合:
- 想要完全掌控自己基础设施的交易者
- 熟悉自托管的技术型用户
- 想免费试用 WolfBot 的人——一个平台覆盖加密货币和 MT5
- 在个人电脑或 VPS 上运行
- 预算有限的交易者

### 你需要自行负责:
- 安装软件
- 保持机器持续运行
- 管理备份
- 网络/防火墙配置
- 应用更新(一键操作,但需手动触发)

### 主要优势:
- ✅ 完全免费
- ✅ 数据始终留在你自己的机器上
- ✅ 无需订阅承诺
- ✅ 与 Cloud 相同的交易引擎——加密货币 + 期货 + MT5
- ✅ 完整的 API 访问权限
- ✅ 通过 GitHub 公开开发

---

## WolfBot Cloud

### 最适合:
- 想要托管、免维护体验的交易者
- 不想自行管理服务器的人
- 无需自己维护电脑/VPS 即可 24/7 交易
- 需要优先技术支持的用户
- 团队和多账户管理场景

### WolfBot.io 负责处理:
- 服务器托管与在线时长
- 基础设施维护
- 自动更新
- 备份与灾难恢复
- 安全监控
- 性能优化

### 主要优势:
- ✅ 无需安装
- ✅ 始终在线——24/7 运行
- ✅ 团队直接提供支持
- ✅ 一切自动化
- ✅ 多账户控制面板
- ✅ 高级分析功能

## 常见的转换路径

### 从 Community 开始 → 转向 Cloud

许多用户会先从 Community 开始:
1. 零风险试用 WolfBot(免费,模拟账户)
2. 在加密货币和 MT5 市场验证策略
3. 熟悉统一界面
4. 准备好 24/7 托管交易时转向 Cloud

### 从 Cloud → 使用 Community

Cloud 用户有时会同时使用 Community 用于:
- 开发和测试
- 在本地运行自定义策略
- 作为备用交易环境
- 对隐私敏感的操作

可以!你可以同时运行两者:

- **Cloud** 用于生产环境的 24/7 交易

它们是相互独立的安装,互不干扰。

## 常见问题

**问:Community 是 Cloud 的"精简版"吗?**
不是。Community 拥有相同的交易引擎、策略和经纪商支持——同一个统一平台,涵盖加密货币、期货和 MT5。区别只在于托管方式和技术支持。

**问:Community 会一直免费吗?**
是的。WolfBot Community 是我们的承诺——为每个人提供一个免费的、自托管的统一交易平台。

**问:我可以从 Community 迁移到 Cloud 吗?**
可以。导出你的配置和策略,我们的团队会协助你完成迁移。

**问:Cloud 有 Community 没有的功能吗?**
Cloud 包含托管服务、团队功能、高级分析和直接技术支持。核心交易引擎——包括所有市场支持——完全相同。
