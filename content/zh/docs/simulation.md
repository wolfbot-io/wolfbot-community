# 从模拟账户开始

**已在 WolfBot Community v0.1.0-p12-ghcr-rc8 上测试** · 最后更新: 2026-08-15

## WolfBot 中的"模拟"是什么?

WolfBot 并没有一个可以单独打开/关闭的全局"模拟模式"开关。你只需连接经纪商自带的 **模拟(测试网)账户**——与实盘交易完全相同的界面、相同的风控引擎、相同的订单逻辑,唯一区别是使用虚拟资金而非真实资金,交易数据依然来自真实的实时市场行情。模拟和实盘之间,平台本身没有任何区别;唯一的区别是你正在交易哪个账户。

以 Bybit 为例,WolfBot 会自动识别一个 API 密钥属于模拟账户还是实盘账户——你不需要手动选择模式。

## 为什么要从模拟账户开始?

1. **零风险** —— 不涉及任何真实资金
2. **熟悉界面** —— 了解跨市场的订单、持仓和风险控制
3. **测试策略** —— 在实盘前,先在加密货币和 MT5 品种上验证你的思路
4. **建立信心** —— 观察 WolfBot 在不同资产类别的市场波动中如何反应

## 第一步:连接模拟账户

1. 打开 WolfBot Community → **交易所账户 → 添加账户**
2. 选择 **Bybit**,创建一个模拟/测试网 API 密钥——具体步骤见 [Bybit 连接指南](/brokers/bybit)
3. 粘贴密钥。WolfBot 会自动识别这是一个模拟密钥,并相应地标记账户
4. MT5 用户:大多数 MT5 经纪商也提供免费模拟账户——请在经纪商的控制面板中查看,然后按照 [MT5 连接指南](/brokers/mt5) 操作

## 第二步:探索智能终端

智能终端是你的手动交易界面——你以后进行实盘交易时用的也是同一个界面。

1. 进入 **智能终端**
2. 选择你的模拟账户,再选择一个交易对(例如加密货币的 BTC/USDT,或通过 MT5 交易黄金的 XAU/USD)
3. 注意预填的风控参数:
   - 仓位大小
   - 止损
   - 止盈
4. 点击 **下单**

你的订单会立即出现在 **持仓** 面板中——资金来自你模拟账户的虚拟余额。

## 第三步:观察你的模拟投资组合

1. 进入 **投资组合概览**
2. 查看你模拟账户的余额和盈亏
3. 观察持仓随真实市场价格实时更新
4. 观察止盈/止损位如何保护你的持仓

## 第四步:配置风险控制

即使在模拟账户上,也请养成良好的风险管理习惯——这些设置在你连接实盘账户后会原样保留:

1. **仓位限制** —— 每笔交易的最大仓位
2. **回撤保护** —— 停止前的最大亏损
3. **冷却时间** —— 交易之间的最短间隔
4. **每日限制** —— 每天最大交易次数

> 🛡️ 风控设置在模拟账户和实盘账户上的工作方式完全相同。现在就配置好,实盘时即可直接使用。

请查看[风险控制指南 →](/docs/risk-controls)

## 第五步:试用自动化机器人

1. 进入 **机器人 → 创建机器人**
2. 选择一个策略模板
3. 配置参数
4. 将机器人指向你的模拟账户
5. 观察它自动执行交易——加密货币和 MT5 品种运行的是同一套逻辑

## 切换到实盘交易

当你准备好时:
1. 使用一个实盘、仅限交易的 API 密钥连接经纪商账户(参见[连接你的市场](/getting-started))
2. 从最小仓位开始
3. 保持严格的止损设置
4. 在验证运行状况后逐步增加仓位

> ⚠️ 即使是经验丰富的交易者,也应先在模拟账户上测试新策略——在跨不同市场类型交易时尤其如此。

## 常见问题

**问:模拟账户使用的是真实市场数据吗?**
是的。无论是模拟账户还是实盘账户,WolfBot 都会从交易所和 MT5 经纪商获取实时价格。

**问:模拟账户会亏钱吗?**
不会。模拟账户使用的是交易所/经纪商提供的虚拟资金,而非真实资金。

**问:模拟和实盘的真实程度有多接近?**
WolfBot 在两者上运行完全相同的订单逻辑。主要区别在于成交环节——模拟账户是对着交易所的测试网撮合,而不是真实订单簿,因此滑点可能略有不同。无论你交易的是加密货币、外汇还是黄金,这一点都是一样的。

**问:我可以重置我的模拟账户余额吗?**
这取决于交易所,而不是 WolfBot——大多数经纪商允许你在其自己的官网上为模拟账户充值或重置虚拟余额(例如 Bybit 的测试网控制面板)。
