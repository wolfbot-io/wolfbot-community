# 自托管交易平台详解

**已在 WolfBot Community v0.1.0-beta.4 上测试** · 最后更新: 2026-08-15

## "自托管"是什么意思?

自托管交易平台运行在**你自己**的电脑上——你的 Windows 电脑、Linux 机器,或 VPS。由你安装,由你配置,由你掌控。你所有的市场、所有的策略、所有的数据——全部由你自己掌控。

```text
云托管:
你的浏览器 → 别人的服务器 → 交易所

自托管(WolfBot Community):
你的机器 → 交易所(直接连接)
```

---

## 为什么要自托管?

### 1. 完全掌控
- 你的机器,你说了算
- 没有第三方能暂停你的交易
- 由你决定何时更新
- 不存在服务被单方面停止的风险

### 2. 隐私保护
- API 密钥留在你自己的机器上
- 交易数据保留在本地
- 没有云数据库存储你的策略
- 没有任何第三方能看到你的持仓——无论哪个市场

### 3. 零成本
- WolfBot Community 完全免费
- 没有订阅费用
- 没有按笔交易收费
- 唯一的成本是你自己的电费/网费
- 一个平台覆盖你所有的市场——加密货币、期货和 MT5

### 4. 安全性
- 非托管:没有第三方持有你的资金
- 仅限交易的 API 密钥:提现根本无法进行
- 你自己的防火墙,你自己的安全规则
- 没有共享基础设施带来的攻击面

### 5. 高度可定制

- 完全访问所有功能
- 在所有已连接的市场上运行自定义策略
- 与你自己的工具集成
- 按你的工作流程自由调整

## 常见疑虑

### "我需要一台服务器吗?"
不需要。WolfBot Community 在普通的 Windows 或 Linux 电脑上就能正常运行。只有当你想在[不让电脑一直开机的情况下实现 24/7 交易](/docs/run-24-7-on-a-vps)时,才需要一台 VPS。无论在哪种环境下,它对加密货币交易所和 MT5 经纪商的支持都同样完善。

### "如果我的电脑崩溃了怎么办?"
你的持仓在交易所,而不是在你的电脑上。WolfBot Community 是非托管的。当你重启后,它会自动恢复你的持仓——无论是加密货币交易对还是 MT5 品种。

### "它安全吗?"
是的——在很多方面比云端方案更安全。你的 API 密钥永远不会离开你的机器。网络访问由你自己掌控。即使有人获得了访问权限,仅限交易的 API 密钥也能阻止提现。

### "如果我不懂技术,还能用吗?"
可以。Windows 安装程序是标准的安装向导——双击、安装、打开即可。Linux 使用标准的 .deb 安装包。不需要任何编程或 Docker 经验。

## 自托管适合你吗?

### ✅ 如果你符合以下情况,自托管很适合你:
- 想把成本控制在零
- 更喜欢掌控自己的基础设施
- 重视隐私和数据所有权
- 有一台可以保持开机的电脑(或一台 VPS)
- 能接受基本的电脑设置操作

### ❌ 如果你符合以下情况,云托管可能更适合你:
- 不想管理任何基础设施
- 需要有保障的 24/7 在线时长
- 更喜欢直接的技术支持
- 想要完全托管的体验
