# 智能终端指南

**已在 WolfBot Community v0.1.0-beta.9 上测试** · 最后更新: 2026-08-15

## 什么是智能终端?

智能终端是 WolfBot Community 的手动交易界面。与普通交易所的交易界面不同,它会自动将你的风控设置——仓位限制、止损、止盈——应用到你下的每一笔订单上。无论你是在 Binance 交易加密货币、在 Bybit 交易期货,还是通过 MT5 交易黄金,它的工作方式完全一致。

## 核心概念

| 功能 | 作用 |
|---|---|
| **风控感知下单** | 根据你的风控设置自动计算仓位大小 |
| **自动止盈/止损** | 自动附带止盈和止损订单 |
| **智能限价** | 根据市场深度智能路由订单 |
| **持仓监控** | 所有持仓的实时盈亏追踪 |

## 使用方法

### 1. 打开智能终端

1. 启动 WolfBot Community
2. 在侧边栏点击 **智能终端**
3. 选择交易对(例如加密货币的 BTC/USDT,外汇的 EUR/USD,或黄金的 XAU/USD)
4. 选择你的经纪商账户

### 2. 配置你的订单

终端会根据你的风控配置预填以下数值:

- **仓位大小** —— 根据你的风险百分比和账户余额计算得出
- **止损** —— 根据你的风控参数自动设置
- **止盈** —— 根据你的盈亏比自动设置
- **订单类型** —— 市价单、限价单或智能限价单

### 3. 下单

1. 检查预填的参数
2. 如需调整可自行修改(如超出风控限制,终端会提示警告)
3. 点击 **买入** 或 **卖出**
4. 确认订单详情
5. 你的订单将带着止盈/止损保护一并下达

### 4. 监控持仓

下单后:
- 持仓会出现在 **持仓** 面板中
- 盈亏实时更新
- 止盈/止损位可见
- 你可以在终端中修改或平仓

## 风险安全网

智能终端会自动强制执行:

- **仓位上限** —— 不能超过你配置的最大值
- **必须设置止损** —— 每个持仓都必须有止损(可配置)
- **冷却计时器** —— 防止快速连续下单(可配置)
- **每日交易限制** —— 每天最大交易数(可配置)

请前往[风险控制 →](/docs/risk-controls)配置你的安全参数。

## 模拟账户与实盘账户

没有单独的终端模式需要切换——你在第一步中选择的账户就决定了一切:

| 账户类型 | 工作方式 |
|---|---|
| **模拟** | 订单在经纪商的测试网上以虚拟资金撮合——零风险 |
| **实盘** | 订单在你真实的交易所或 MT5 经纪商账户上执行 |

无论哪种账户,智能终端的行为都完全一致——相同的风控、相同的订单逻辑。

> ⚠️ 切换到实盘前,请务必先在模拟账户上测试。参见[模拟账户指南 →](/docs/simulation)

## 订单类型

### 市价单
以当前最优可用价格立即成交。

### 限价单
只在你指定的价格或更优价格成交。

### 智能限价单
WolfBot 会监控订单簿,在条件最优时执行——在价格和成交概率之间取得平衡。

## 常见操作

| 操作 | 方法 |
|---|---|
| 市价买入 | 选择交易对 → 点击 **市价买入** |
| 限价买入 | 选择交易对 → 选择 **限价** → 设置价格 → 点击 **买入** |
| 设置止盈/止损 | 根据风控配置自动设置;也可在持仓面板手动覆盖 |
| 平仓 | 点击持仓 → **平仓** |
| 修改止盈/止损 | 点击持仓 → 编辑止盈/止损数值 → 确认 |
| 查看订单历史 | 侧边栏的 **活动** 标签 |

## 故障排查

- **"Risk limit exceeded"(超出风险限制)** —— 减小仓位或调整风控设置
- **"Cooldown active"(冷却中)** —— 等待冷却时间结束
- **"Insufficient balance"(余额不足)** —— 检查你的交易所或 MT5 经纪商账户余额
- **"Order rejected"(订单被拒绝)** —— 检查交易所最小订单要求或 MT5 手数要求
