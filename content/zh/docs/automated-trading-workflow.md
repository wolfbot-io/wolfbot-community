# 使用 WolfBot Community 自动化交易

**已在 WolfBot Community v0.1.0-p12-ghcr-rc21 上测试** · 最后更新: 2026-08-15

## 本指南适合谁

- **如果你想让机器人替你交易** —— 本文用通俗的语言带你走完整个流程,从选择策略到安全运行,让你确切知道点击"启动"之后会发生什么。
- **如果你比较偏技术型** —— 你会看到 WolfBot 是如何把*每一笔*自动化订单都包裹在与手动交易相同的风控引擎中的——这正是防止一个自动化机器人因小 bug 而酿成大亏损的关键。

## 这里说的"自动化交易"是什么意思

WolfBot Community 中的自动化交易,是指你配置一次之后就让它持续运行的机器人:它会监控市场,按照某个策略决定何时入场和出场,并替你下单。你不需要手动点击每一笔交易——但你依然掌控着两件最重要的事:它遵循的策略,以及它必须遵守的风控限制。

## 完整工作流程

```text
1. 选择一个策略模板
2. 配置策略参数
3. 先指向一个模拟账户
4. 让风控引擎包裹每一笔订单
5. 检查表现后,再指向实盘
```

### 1. 选择一个策略模板

在**机器人**区域,你创建一个机器人并选择一个策略模板——作为机器人决定买卖时机的起点。你不需要编写代码;只需选择一个模板并调整它的参数。

### 2. 配置策略参数

每个策略都有自己的一套设置(入场/出场规则、时间周期、交易品种)。一开始请设置得保守一些——等你观察到机器人在真实市场数据上的表现后,随时可以放宽。

### 3. 先指向一个模拟账户

在任何真实资金动用之前,先让机器人在[模拟账户](/docs/simulation)上运行。它会用虚拟资金交易真实的市场数据,让你能零成本地确切观察这个策略的表现——包括它的连续亏损情况。

### 4. 风控引擎会包裹每一笔订单

这是最重要的部分。自动化机器人会自动下单,但它下的每一笔订单,依然会经过与手动交易相同的[风险控制](/docs/risk-controls):

- **仓位上限** —— 一个错误的信号也无法开出过大的仓位
- **回撤保护** —— 连续亏损会让机器人暂停,而不是让亏损不断累积
- **冷却时间** —— 订单之间的最短间隔,亏损后间隔更长
- **每日交易限制** —— 总订单数的上限

所以机器人可以*建议*交易,但无法绕过你的安全限制。

### 5. 检查表现后,再切换到实盘

当你对机器人在模拟账户上的表现感到满意后,将同样的配置指向一个实盘的[仅限交易 API 密钥](/brokers/api-key-guide),并从你能设置的最小仓位开始。

## 一个机器人,覆盖每个市场

WolfBot Community 中的机器人在你所有已连接的账户上工作方式完全相同,和手动交易一样——无论是 Binance 或 Bybit 上的加密货币、期货,还是 MT5 品种(外汇、黄金、指数)。策略逻辑和风控引擎在不同市场之间不会改变;唯一变化的只是机器人交易的账户。

## 常见错误

| 错误 | 解决方法 |
|---|---|
| 未经模拟账户测试就直接实盘 | 先在[模拟账户](/docs/simulation)上运行策略,观察完整的一轮连续亏损 |
| 为了"方便测试"而关闭风控限制 | 请保持开启——它们在模拟账户上同样生效,没有理由关闭 |
| 每个市场用一个机器人、各套不同的规则 | 在所有账户上使用同一个风控引擎,这样某个市场的亏损就无法逃过保护机制 |
| 忽略冷却时间 | 短暂的冷却时间可以防止机器人在快速波动的市场中连续开火 |

## 故障排查

- **机器人下了一笔意外的订单** —— 检查策略参数以及它所受到的[风险控制](/docs/risk-controls)
- **机器人自行暂停了** —— 这是回撤保护或每日限制在起作用;查看风险页面了解触发了哪项限制
- **订单被拒绝** —— 检查交易所的最小订单要求、手数要求(MT5)以及你的账户余额。参见[故障排查](/docs/troubleshooting)
