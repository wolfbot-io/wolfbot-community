# Установка WolfBot Community на Ubuntu/Linux

**Протестировано с WolfBot Community v0.1.0-beta.9** · Последнее обновление: 2026-08-15 · Ubuntu 24.04 / Ubuntu 22.04 / Debian 12

## Для кого это руководство

Для тех, кто хочет установить WolfBot Community на Ubuntu или Debian — **вам не нужно уметь пользоваться терминалом или Docker.** Всё ниже использует ту же установку двойным щелчком, что и для любого другого приложения; альтернатива через командную строку приведена далее для тех, кто её предпочитает.

## Что вам понадобится

- Ubuntu 22.04 LTS, Ubuntu 24.04 LTS или Debian 12 (64-бит)
- Не менее 4 ГБ ОЗУ, 4 ГБ свободного места на диске
- Подключение к интернету
- Пароль вашей учётной записи (его спросят один раз, чтобы разрешить установку — это совершенно нормально, так поступает любой установщик приложений в Linux)

> ℹ️ Для работы WolfBot нужен Docker. Если он ещё не установлен, установщик установит его автоматически — ничего настраивать вручную не нужно.

## Шаг 1: Скачивание

1. Перейдите на [community.wolfbot.io/download](https://community.wolfbot.io/download)
2. Нажмите **Download for Linux**
3. Файл `WolfBot-Setup-linux-amd64.deb` загрузится в папку **Загрузки**

## Шаг 2: Установка (двойной щелчок, как в любом другом приложении)

1. Откройте папку **Загрузки** и **дважды щёлкните** по файлу `WolfBot-Setup-linux-amd64.deb`
2. Откроется окно установщика приложений вашей системы (обычно называется «Установка ПО» или «Package Installer»)
3. Нажмите **Установить**
4. Введите пароль, когда попросят, затем нажмите Enter/OK
5. Дождитесь завершения — в первый раз это может занять минуту-две, так как в фоне также настраивается Docker

Вот и всё — терминал не нужен.

> **Не появилось окно установки?** Некоторые версии Ubuntu по умолчанию открывают файлы `.deb` в просмотрщике архивов вместо установщика.
> Щёлкните правой кнопкой по файлу → **Открыть с помощью** → выберите **Установка ПО** (или **GDebi Package Installer**, если он есть) → затем нажмите **Установить**.

## Шаг 3: Запустите WolfBot

1. Откройте меню **Приложения** (или нажмите клавишу Windows/Super и введите «WolfBot»)
2. Нажмите на значок **WolfBot**
3. Ваш браузер автоматически откроет панель управления WolfBot

## Ожидаемый результат

- Значок WolfBot появляется в меню Приложения
- При нажатии открывается панель управления в браузере
- Страница «Статус возможностей» на панели показывает, каких брокеров можно подключить — начните с [демо-счёта](/docs/simulation) для торговли с нулевым риском

## Торгуйте форекс, золотом и индексами через MT5 — без Windows

WolfBot Community — это **единая платформа**: криптобиржи и MT5 (форекс, золото, индексы, акции/CFD) в одном интерфейсе, с одним риск-движком, одним портфелем — в том числе на Linux, без отдельного компьютера с Windows или VPS. MT5 работает как настоящий терминал рядом с остальной частью WolfBot, и вы управляете им из собственного браузера. Активируйте его одной командой — точные шаги см. в [руководстве по подключению MT5](/brokers/mt5).

## Частые ошибки

| Ошибка | Решение |
|---|---|
| Двойной щелчок открывает архив вместо установки | Щёлкните правой кнопкой по файлу → Открыть с помощью → Установка ПО |
| Запрос «Требуется аутентификация» | Это нормально — введите ваш обычный пароль для входа |
| После нажатия «Установить» ничего не происходит | Подождите минуту — в первый раз в фоне настраивается Docker |
| Не могу найти WolfBot после установки | Выйдите из системы и снова войдите, или найдите «WolfBot» в меню Приложения |

## Предпочитаете командную строку?

Если вам удобнее с терминалом, вот команды, делающие то же самое, что и шаги выше:

```bash
cd ~/Downloads
sudo apt install ./WolfBot-Setup-linux-amd64.deb
```

Использование `apt install ./file.deb` (а не `dpkg -i`) автоматически разрешает любые недостающие зависимости за один шаг.

Полезные команды после установки:

```bash
wolfbot status     # проверить сервисы
wolfbot start      # запустить WolfBot
wolfbot open       # открыть панель управления в браузере
wolfbot logs       # просмотреть логи
```

Адрес панели управления: `http://127.0.0.1:8765`

## Решение проблем

- **Ничего не открывается при нажатии на значок WolfBot** — подождите минуту после свежей установки (контейнеры Docker ещё запускаются), затем попробуйте снова.
- **«Порт занят» или панель управления не загружается** — что-то другое на вашем компьютере может использовать порт 8765. См. [Руководство по решению проблем](/docs/troubleshooting), как это проверить.
- Всё ещё не получается? См. полное [Руководство по решению проблем](/docs/troubleshooting) или спросите в [Обсуждениях на GitHub](https://github.com/wolfbot-io/wolfbot-community/discussions).

## Удаление

Откройте магазин приложений вашей системы (например, **Ubuntu Software**), найдите «WolfBot» и нажмите **Удалить** — так же, как вы удалили бы любое другое приложение, установленное через файл `.deb`.

Или через терминал:

```bash
sudo apt remove wolfbot-community
rm -rf ~/.wolfbot    # опционально: также удалить локальные данные WolfBot
```
