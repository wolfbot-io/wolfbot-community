# Установка WolfBot Community на Windows

**Протестировано с WolfBot Community v0.1.0-beta.9** · Последнее обновление: 2026-08-15 · Windows 11 / Windows 10

> ℹ️ **Доступность:** первый публичный релиз (v0.1.0-beta.9) поставляется с установщиком для Linux. Установщик для Windows описан здесь заранее, до его выхода в следующем релизе — проверьте [страницу загрузки](/download) для актуального статуса, и это руководство проведёт вас по шагам, как только он станет доступен.

## Для кого это руководство

Это руководство для тех, кто хочет установить WolfBot Community на компьютер с Windows 10 или Windows 11. Не требуется опыт программирования или работы с Docker. После установки у вас будет единая торговая платформа для криптобирж и брокеров MT5 — один интерфейс, каждый рынок.

## Что вам понадобится

- Windows 10 (22H2 или новее) или Windows 11 (23H2 или новее), 64-бит
- Не менее 4 ГБ свободной оперативной памяти
- Не менее 2 ГБ свободного места на диске
- Подключение к интернету
- Права администратора для установки программ

> ⚠️ **Об антивирусах:** некоторые антивирусы могут помечать новое ПО. Установщики WolfBot Community безопасны — это официальные сборки от WolfBot.io. Если антивирус блокирует установщик, добавьте исключение или временно отключите его.

## Шаг 1: Скачивание

1. Перейдите на [community.wolfbot.io/download](https://community.wolfbot.io/download)
2. Нажмите **Download for Windows**
3. Загрузится файл `WolfBot-Setup-{version}-windows-x64.exe`

## Шаг 2: Установка

1. Дважды щёлкните по загруженному файлу `WolfBot-Setup-*.exe`
2. Если появится Windows SmartScreen, нажмите **Подробнее** → **Всё равно выполнить**
3. Следуйте мастеру установки: выберите папку → нажмите **Установить**
4. Дождитесь завершения установки (обычно 30–60 секунд)
5. Нажмите **Готово**

## Шаг 3: Запустите WolfBot

1. Дважды щёлкните по значку **WolfBot** на рабочем столе (или в меню Пуск)
2. WolfBot откроет панель управления — счёт на бирже ещё не подключён, поэтому перед изучением ничего настраивать не нужно

## Ожидаемый результат

- Значок WolfBot в системном трее
- Открывается окно панели управления
- Страница «Статус возможностей» на панели показывает, каких брокеров можно подключить

## Частые ошибки

| Ошибка | Решение |
|---|---|
| «Windows защитила ваш компьютер» | Нажмите «Подробнее» → «Всё равно выполнить» |
| Установщик не запускается | Правой кнопкой мыши → «Запуск от имени администратора» |
| Антивирус поместил в карантин | Добавьте `C:\Program Files\WolfBot` в исключения |
| Ошибка «отсутствует DLL» | Установите [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) — небольшой бесплатный официальный компонент Microsoft, необходимый многим приложениям Windows; установка безопасна |

## Решение проблем

- **WB-WIN-001:** недостаточно места на диске → освободите 2 ГБ
- **WB-WIN-002:** отказано в доступе → запустите от имени администратора
- **WB-WIN-003:** повреждённая загрузка → скачайте заново, проверьте контрольную сумму
- **WB-WIN-004:** отсутствуют зависимости → установите VC++ Redist

См. [Руководство по решению проблем](/docs/troubleshooting).

## Дополнительно: проверьте вашу загрузку (необязательно)

Если вы хотите убедиться, что файл не был повреждён или изменён, откройте PowerShell и выполните:

```powershell
Get-FileHash .\WolfBot-Setup-*.exe -Algorithm SHA256
```

Сравните результат с контрольной суммой SHA256, указанной на
[странице загрузки](https://community.wolfbot.io/download). Этот шаг
необязателен — большинство пользователей могут его пропустить.
