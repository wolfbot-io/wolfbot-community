# Начало работы с WolfBot Community

**Протестировано с WolfBot Community v0.1.0-beta.2** · Последнее обновление: 2026-08-15

## Добро пожаловать! 👋

WolfBot Community — это единая торговая платформа: один интерфейс для криптобирж и брокеров MT5. Установка не создаёт никакого счёта на бирже и не совершает никаких сделок — ничего не подключено, пока вы сами не добавите счёт. Выполните следующие шаги по порядку.

> **Одна платформа. Каждый рынок.** — Крипто + фьючерсы + MT5, объединённые в WolfBot.

## Шаг 1: Откройте панель управления

Запустите WolfBot Community. Вы попадёте на страницу **Статус возможностей** — она показывает, какие брокеры и функции доступны в вашей установке, и подтверждает, что пока ничего не подключено.

## Шаг 2: Изучите панель управления

| Раздел | Назначение |
|---|---|
| **Обзор портфеля** | Баланс, прибыль/убыток, позиции — по ВСЕМ подключённым рынкам |
| **Боты** | Автоматизированные торговые боты для крипто и MT5 |
| **Умный терминал** | Ручная торговля с контролем рисков |
| **Управление рисками** | Лимиты позиций, защита от просадки |
| **Счета на биржах** | Подключения к брокерам и API-ключи |

## Шаг 3: Подключите демо-счёт — нулевой риск

У WolfBot нет отдельного переключателя «режима симуляции». Вместо этого вы подключаете собственный **демо-счёт (testnet)** брокера — реальные рыночные данные, виртуальные средства, тот же самый интерфейс и тот же риск-движок, которые вы будете использовать позже для реальной торговли.

1. Перейдите в **Счета на биржах → Добавить счёт**
2. Выберите **Bybit** и следуйте [шагам настройки демо-счёта Bybit](/brokers/bybit) — WolfBot автоматически определяет, демо это или реальный счёт, по вставленному вами API-ключу
3. Попробуйте **Умный терминал** с вашим демо-счётом
4. Наблюдайте, как позиции появляются на панели управления

> ✅ Демо-счёт ничего не стоит и никогда не затрагивает реальные средства — это самый безопасный способ изучить WolfBot на любом поддерживаемом рынке.

[Полное руководство по демо/симуляции →](/docs/simulation)

## Шаг 4: Подключите ваши рынки для реальной торговли

Когда будете готовы перейти к реальной торговле:
1. Создайте API-ключ только для торговли на вашей бирже
2. Счета на биржах → Добавить счёт → Выберите брокера → Введите ключи
3. Начните с небольших позиций и строгого контроля рисков

> ⚠️ Всегда используйте API-ключи с правами только для торговли (без вывода средств).

Руководства по брокерам: [Bybit](/brokers/bybit) · [Binance](/brokers/binance) · [BingX](/brokers/bingx) · [KuCoin](/brokers/kucoin) · [Bitget](/brokers/bitget) · [MT5](/brokers/mt5)

## Чек-лист первой недели

- [ ] Изучить панель управления
- [ ] Подключить демо-счёт (демо Bybit или демо MT5)
- [ ] Торговать на демо 1–2 дня
- [ ] Попробовать Умный терминал с демо-счётом
- [ ] Прочитать [Руководство по управлению рисками](/docs/risk-controls)
- [ ] Подключить реальный счёт, когда будете готовы
