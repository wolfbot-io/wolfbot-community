# Каналы релизов — объяснение

**Протестировано с WolfBot Community v0.1.0-beta.9** · Последнее обновление: 2026-08-15

## Доступные каналы

| Канал | Статус | Кому подходит | Авто-обновление |
|---|---|---|---|
| **Stable** | Готов к продакшну | Живым трейдерам | ✅ |
| **RC** (Release Candidate) | Финальное тестирование | Осторожным ранним пользователям | По желанию |
| **Beta** | Предпросмотр функций | Тестерам, энтузиастам | ✅ |
| **Alpha** | Ранний тест функций | Техническим тестерам | По желанию |
| **Dev Preview** | Свежайшие сборки | Разработчикам, для обратной связи | Вручную |

---

## Stable

Готовые к продакшну релизы, прошедшие все этапы контроля качества.

- **Частота обновлений:** каждые 1–2 месяца
- **Риск:** минимальный
- **Лучше всего для:** живой торговли, продакшн-использования
- **Поддержка:** полная поддержка сообщества

> ✅ Рекомендуется для всей живой торговли.

---

## Beta

Функционально полные сборки, проходящие более широкое тестирование.

- **Частота обновлений:** каждые 1–2 недели
- **Риск:** низкий — функции работают, но возможны пограничные случаи
- **Лучше всего для:** тестирования новых функций перед Stable
- **Поддержка:** приветствуется обратная связь сообщества

---

## Dev Preview

Свежайшие сборки разработки — новейшие функции, наименее протестированные.

- **Частота обновлений:** несколько раз в неделю
- **Риск:** средний — функции могут быть неполными
- **Лучше всего для:** разработчиков, ранней обратной связи, энтузиастов
- **Поддержка:** по мере возможности

> ⚠️ Dev Preview может содержать неполные функции. Режим по умолчанию — Simulation.

---

## Как работают каналы

```text
Dev Preview (часто)
    ↓
Alpha (тестирование функций)
    ↓
Beta (широкое тестирование)
    ↓
RC (release candidate)
    ↓
Stable (продакшн)
```

Каждая сборка неизменяема — мы никогда не изменяем опубликованный релиз. Если найдена ошибка, выпускается новая версия.

## Текущий статус

WolfBot Community сейчас находится в публичном релизном канале **v0.1.0-beta.9**.

```text
Stable: ещё не выпущен
Текущая публичная версия: v0.1.0-beta.9
```

Это означает:
- ПО функционально и устанавливаемо
- Функции проходят широкое тестирование
- Между версиями возможны ломающие изменения
- Во время тестирования рекомендуется Demo-аккаунт

---

## Смена канала

В приложении нет переключателя каналов — ваш канал просто тот релиз, который вы скачали и установили. Когда хотите попробовать новые функции, возьмите сборку Beta или Dev Preview из [GitHub Releases](https://github.com/wolfbot-io/wolfbot-community/releases) вместо ссылки Stable на странице загрузки; установщик в любом случае обновит вашу текущую установку на месте.

При использовании более экспериментального канала рекомендуется сначала тестировать на Demo-аккаунте.

## GitHub Releases

Все релизы публикуются на [GitHub Releases](https://github.com/wolfbot-io/wolfbot-community/releases):

- **Pre-release:** Dev Preview, Alpha, Beta, RC
- **Full Release:** только Stable
- Каждый релиз включает: файлы установщика, контрольные суммы, заметки о релизе
