# Гайд по API-ключам только для торговли

**Протестировано с WolfBot Community v0.1.0-p12-ghcr-rc17** · Последнее обновление: 2026-08-15

## Почему только для торговли?

WolfBot Community — **некастодиальный** сервис: он никогда не хранит ваши средства. Он подключается к биржам через API-ключи, которыми управляете вы. Вы можете отозвать эти ключи в любой момент.

**Золотое правило:** никогда не включайте разрешения на вывод (Withdrawal) или перевод (Transfer) у любого API-ключа, используемого с торговым ПО. Смотрите [Объяснение API-ключей только для торговли →](/docs/trade-only-api-keys-explained), почему именно эта настройка важнее любой другой.

## Требуемые разрешения

WolfBot нужны только эти разрешения:

| Разрешение | Требуется | Зачем |
|---|---|---|
| **Trade** (чтение-запись) | ✅ Да | Размещение/отмена ордеров, проверка позиций |
| **Read** (только чтение) | ✅ Да | Чтение баланса, позиций, истории ордеров |
| **Withdrawal** | ❌ НИКОГДА | WolfBot не выводит средства |
| **Transfer** | ❌ НИКОГДА | WolfBot не переводит между аккаунтами |

Если биржа предлагает детальные разрешения, также отключите:
- ❌ **Withdrawal**
- ❌ **Internal Transfer**
- ❌ **Sub-account Transfer**
- ❌ **Earn/Staking** управление

## По биржам

### Binance
1. API Management → Create API
2. Включите: **Enable Spot & Margin Trading**
3. Отключите: **Enable Withdrawals**
4. (Рекомендуется) Ограничьте доверенными IP

### Bybit
1. API Management → Create New Key
2. Включите: разрешение **Trade**
3. Отключите: **Withdrawal**, **Transfer**
4. (Рекомендуется) Привяжите IP-адрес

### BingX
1. API Management → Create API Key
2. Включите: **Trade**
3. Отключите: **Withdrawal**
4. (Рекомендуется) Ограничьте доступ по IP

### KuCoin
1. API Management → Create API
2. Включите: **Trade** в Spot Trading
3. Отключите: **Withdrawal**, **Transfer**
4. Задайте passphrase (обязательно для KuCoin)

### Bitget
1. API Management → Create API Key
2. Включите: **Trade**
3. Отключите: **Withdrawal**
4. (Рекомендуется) Привяжите IP

## Дополнительные советы по безопасности

### Привязка IP (рекомендуется)
Где поддерживается, привязывайте API-ключи к IP-адресу вашей машины:
- Предотвращает использование из других мест
- Обновляйте при смене IP
- Для работы 24/7 используйте статический IP или VPS

### Отдельные ключи на сервис
- Один API-ключ для WolfBot Community
- Другие ключи для приложений отслеживания портфеля
- Упрощает отзыв отдельных интеграций

### Регулярные проверки
- Проверяйте API-ключи ежемесячно
- Удаляйте неиспользуемые ключи
- Периодически пересоздавайте ключи

### Хранение ключей
- Храните секреты API безопасно (WolfBot шифрует их локально)
- Никогда не делитесь ключами в скриншотах или сообщениях поддержки
- Не храните ключи в облачных заметках или электронной почте

## Что делать, если ключ скомпрометирован?

1. **Немедленно** удалите API-ключ на бирже
2. Проверьте аккаунт на несанкционированную активность
3. Создайте новый ключ только для торговли
4. Обновите WolfBot новым ключом

Поскольку вывод отключён, скомпрометированный ключ только для торговли не может украсть средства — но он может размещать нежелательные сделки. Всегда действуйте быстро.
