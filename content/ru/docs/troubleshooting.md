# Гайд по устранению неполадок

**Протестировано с WolfBot Community v0.1.0-p12-ghcr-rc17** · Последнее обновление: 2026-08-15

## Быстрая диагностика

Запустите встроенный инструмент диагностики из терминала (Command Prompt/PowerShell на Windows, обычный терминал на Linux), из папки установки WolfBot:

```bash
wolfbot doctor
```

Он только для чтения — проверяет целостность установки, статус сервисов, сеть и подключения брокеров, ничего не изменяя.

## Ошибки установки

### WB-WIN-001 — Недостаточно места на диске
**Симптом:** установщик завершается с ошибкой «Not enough disk space»

**Решение:** освободите минимум 2 GB. Проверьте место на диске `C:`.

### WB-WIN-002 — Отказано в доступе
**Симптом:** «Access denied» во время установки

**Решение:** щёлкните правой кнопкой по установщику → **Run as Administrator**

### WB-WIN-003 — Повреждённая загрузка
**Симптом:** установщик не запускается или не проходит проверку целостности

**Решение:** скачайте заново с [community.wolfbot.io/download](https://community.wolfbot.io/download). Проверьте контрольную сумму SHA256.

### WB-WIN-004 — Отсутствуют зависимости
**Симптом:** «VCRUNTIME140.dll not found»

**Решение:** установите [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)

### WB-LNX-001 — Docker не найден
**Симптом:** «Docker is not installed»

**Решение:** `sudo apt-get install docker.io` или повторно запустите установщик, который обработает это автоматически.

### WB-LNX-002 — Конфликт порта
**Симптом:** «Port 8765 already in use»

**Решение:** `sudo lsof -i :8765` → остановите конфликтующий сервис → перезапустите WolfBot

## Проблемы подключения

### Ошибка подключения брокера
1. Проверьте, что API-ключ всё ещё действителен (не истёк)
2. Проверьте разрешения API: Trade ✅, Withdrawal ❌
3. Если ограничение по IP: подтвердите, что ваш IP совпадает
4. Проверьте страницу статуса API биржи
5. Для MT5: убедитесь, что терминал MT5 работает и выполнен вход
6. Пересоздайте ключ и добавьте заново

### «Connection Refused»
- Проверьте интернет-соединение
- Убедитесь, что биржа не заблокирована в вашем регионе
- При необходимости попробуйте с VPN

### «Rate Limit Exceeded»
WolfBot обрабатывает это автоматически. Если повторяется, уменьшите частоту бота.

## Проблемы обновления

| Проблема | Решение |
|---|---|
| Проверка обновления не удалась | Проверьте интернет; файрвол может блокировать сервер обновлений |
| Ошибка проверки подписи | Скачайте вручную со [страницы загрузки](/download) |
| Обновление зависло | Перезапустите WolfBot и повторите |
| После обновления WolfBot не запускается | Linux: `wolfbot-updater.sh rollback`. Windows: переустановите Setup.exe предыдущей версии — см. [Гайд по обновлению](/docs/updates) |

## Проблемы производительности

### Высокая загрузка CPU
- Уменьшите число активных торговых пар
- Увеличьте интервал бота (например, 5 мин → 15 мин)
- Закройте неиспользуемые вкладки Dashboard

### Высокое использование памяти
- Перезапустите WolfBot (утечка памяти при работе >7 дней)
- Уменьшите число одновременных стратегий

### Медленный Dashboard
- Используйте современный браузер (Chrome, Edge, Firefox)
- Очистите кэш браузера
- Уменьшите число виджетов Dashboard

## Данные и конфигурация

### Потерянная конфигурация
1. Если есть архив резервной копии, восстановите его — см. [Гайд по резервному копированию и восстановлению](/docs/backup)
2. Если нет: настройте заново вручную

### Повреждение базы данных
```bash
wolfbot repair
```
Это специальная, fail-closed команда восстановления — она никогда не восстанавливает автоматически без вашего запуска и не трогает ничего, в чём не уверена.

## Логи

Подробные логи для отладки:

**Windows:** `C:\Program Files\WolfBot\logs\`

**Linux:** `~/.wolfbot/logs/` или `wolfbot logs`

При сообщении о проблемах на [GitHub](https://github.com/wolfbot-io/wolfbot-community/issues) прикрепляйте соответствующие фрагменты логов (удаляйте API-ключи).
