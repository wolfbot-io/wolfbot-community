# Как проверить скачанного торгового бота

**Протестировано с WolfBot Community v0.1.0-p12-ghcr-rc21** · Последнее обновление: 2026-08-18

## Для кого этот гайд

- **Если вы скачали торгового бота (или собираетесь это сделать) и хотите убедиться, что это подлинный файл** — здесь показаны две проверки, которые займут две минуты.
- **Если вы технически подкованы** — вы увидите, как самостоятельно подтвердить бинарник, используя дайджест и подпись, которые публикуют мейнтейнеры.

## Зачем вообще проверять

Торговое ПО работает с вашими биржами и вашими деньгами. Любой может опубликовать бинарник под именем «WolfBot» — самая безопасная привычка — убедиться, что файл действительно является тем, чем он себя называет, **прежде чем** вы его запустите. Проверить это можно по двум признакам:

1. **Откуда он взялся** — официальный источник релиза.
2. **Чем файл является на самом деле** — совпадающий дайджест и подпись.

## Проверка за две минуты

**1. Используйте официальный источник.**

Скачивайте только с официального репозитория GitHub (`github.com/wolfbot-io/wolfbot-community`) или с `community.wolfbot.io`. Файл, предложенный где-то ещё — случайный блог, зеркальный сайт, личное сообщение, — по определению не проверен.

**2. Сравните контрольную сумму.**

WolfBot публикует **дайджест SHA-256** для каждого установщика (вы увидите его на странице загрузки и в примечаниях к релизу). После скачивания:

```bash
# Linux/macOS
sha256sum WolfBot-Setup-linux-amd64.deb
# Windows (PowerShell)
Get-FileHash .\WolfBot-Setup.exe -Algorithm SHA256
```

Результат должен точно совпадать с опубликованным дайджестом. Несовпадение означает, что файл не является оригиналом — не устанавливайте его.

**3. (Технически) проверьте подпись.**

Официальные релизы криптографически подписаны. Проверка подписи по публичному ключу проекта подтверждает, кто именно собрал файл, независимо от его хеша.

## Тревожные признаки

- Дайджест **не** совпадает с опубликованным.
- Файл получен не из официального репозитория / сайта сообщества.
- Страница, с которой вы скачали файл, не является настоящим доменом wolfbot.io/github.
- Вас просят запустить установщик от имени администратора из непроверенного источника.

В любом из этих случаев остановитесь и скачайте файл из официального релиза.

## Почему WolfBot Community публикует это

Прозрачность — часть безопасного self-hosting-а. Поскольку вы всегда можете проверить, что устанавливаете, вам никогда не придётся доверять имени на странице загрузки на слово.
