# Запуск WolfBot Community 24/7 на VPS

**Протестировано с WolfBot Community v0.1.0-p12-ghcr-rc21** · Последнее обновление: 2026-08-15 · Ubuntu 22.04 / 24.04

## Для кого этот гайд

Здесь ценность получают два типа читателей:

- **Если вы просто хотите, чтобы ваши боты работали круглосуточно** — чтобы не
  пропустить сделку, пока ваш компьютер выключен — выполняйте шаги ниже по порядку.
  Каждая команда копируется, и вам не нужно понимать механику, чтобы получить
  результат.
- **Если вам комфортно с серверами** и вы хотите знать, *почему* каждый шаг сделан
  именно так (панель только на loopback, SSH-туннель), примечания объясняют логику,
  не мешая вам.

Короче: этот гайд размещает ваш WolfBot Community на небольшом постоянно включённом
Linux-сервере (VPS), чтобы он продолжал торговать ночью — ваши стратегии, настройки
и аккаунты остаются ровно такими, как вы их оставили, а боты продолжают работать,
даже когда ваш личный компьютер выключен.

## Что вам нужно

- Ubuntu 22.04 LTS или 24.04 LTS VPS (подойдёт любой основной провайдер — Hetzner,
  DigitalOcean, Vultr, Linode, AWS Lightsail и т.д.)
- Минимум 4 GB RAM и 4 GB дискового пространства
- Возможность открыть терминал и зайти на сервер по SSH
- 15 минут

> ℹ️ WolfBot Community работает в Docker. Установщик настраивает Docker за вас
> автоматически, ровно как на десктопной Linux-установке.

## Шаг 1: Получите VPS и подключитесь

1. Создайте сервер Ubuntu 22.04/24.04 с минимум 4 GB RAM
2. Подключитесь по SSH (большинство провайдеров дают эту команду на своей странице):

```bash
ssh your-user@your-server-ip
```

## Шаг 2: Установите WolfBot Community (как на десктопе)

Следуйте ровно [гайду установки на Linux](/install/linux) — шаги идентичны на сервере:

1. Скачайте `.deb` с [community.wolfbot.io/download](https://community.wolfbot.io/download)
2. Установите его (на headless-сервере вы используете терминальную форму):

```bash
sudo apt install ./WolfBot-Setup-linux-amd64.deb
```

3. Запустите WolfBot и проверьте, что он здоров:

```bash
wolfbot start
wolfbot status
```

## Шаг 3: Безопасно получите доступ к панели (SSH-туннель)

WolfBot Community привязывает свою панель только к **loopback-адресу сервера
(127.0.0.1)** — это намеренно: это значит, что торговая панель никогда не открыта в
публичный интернет по умолчанию. На вашем домашнем компьютере браузер открывает её
напрямую. На VPS вы добираетесь до неё через зашифрованный SSH-туннель:

```bash
ssh -L 8080:127.0.0.1:8080 your-user@your-server-ip
```

Затем откройте **http://localhost:8080** в браузере. Туннель перенаправляет ваш
локальный порт 8080 на панель на сервере поверх SSH — никаких открытых портов, никакого
публичного URL, ничего для файрвола.

> 🔎 **Для технических читателей:** сервисы WolfBot Community по дизайну привязываются
> к `127.0.0.1` (loopback) — control-api на `8765`, gateway на `8766`, а панель на
> `8080`. Только loopback означает, что торговая поверхность никогда не достижима из
> интернета, поэтому SSH-туннель — правильный (и простейший) способ добраться до неё
> удалённо, а не открывать публичный порт.

> ⚠️ **Не** открывайте панель в публичный интернет. Держите её на loopback и используйте
> SSH-туннель. Панель управляет реальной торговлей, поэтому она должна оставаться
> приватной.

## Шаг 4: Делайте резервные копии на сервере

Теперь ваша конфигурация живёт на вашем VPS, поэтому делайте её резервную копию там:

```bash
wolfbot backup --install-root /opt/wolfbot --data-root /var/lib/wolfbot --execute
```

Затем скопируйте архив с сервера для сохранности. Полный процесс в [гайде по
резервному копированию и восстановлению](/docs/backup).

## Шаг 5: Держите его обновлённым

На сервере обновления идут через подписанный апдейтер:

```bash
/opt/wolfbot/launcher/wolfbot-updater.sh check
```

Шаги apply/rollback в [гайде по обновлению](/docs/updates).

## Ожидаемый результат

- WolfBot Community работает в Docker на вашем VPS, независимо от вашего ПК
- Вы добираетесь до панели через SSH-туннель (только loopback, без публичного порта)
- Боты продолжают торговать и стратегии продолжают работать, пока ваш компьютер выключен

## Частые ошибки

| Ошибка | Исправление |
|---|---|
| Открытие панели в публичный интернет | Не делайте этого — используйте SSH-туннель, держите только loopback |
| Забыли делать резервные копии на сервере | `wolfbot backup ... --execute`, затем скопируйте архив с сервера |
| Сервер перезагрузился, а WolfBot не работает | `wolfbot status` для подтверждения; при необходимости `wolfbot start` |
| Туннель обрывается, когда ноутбук засыпает | Перезапустите команду `ssh -L ...`; это обычное переподключение |

## Устранение неполадок

- **Не могу добраться до localhost:8080 через туннель** — подтвердите, что команда
  туннеля всё ещё работает и `wolfbot status` показывает здоровые сервисы.
- **SSH connection refused** — проверьте, что файрвол вашего VPS разрешает SSH
  (порт 22) и что вы используете правильные user/IP.
- Другие проблемы — см. полный [гайд по устранению неполадок](/docs/troubleshooting).
