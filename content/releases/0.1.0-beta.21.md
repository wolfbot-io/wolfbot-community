# WolfBot Community v0.1.0-beta.21

**Tested with WolfBot Community v0.1.0-beta.21** · Last updated: 2026-11-17

WolfBot Community v0.1.0-beta.21 is the latest public release of the free, self-hosted WolfBot trading platform. It adds the **AI Analyst** (a read-only review of your own trade history), makes the Linux installer **download only the Live Translate images your machine can actually run**, installs a **safe bridge from Docker containers to a local Ollama**, fills **missing daily ROI days** after a PC was off, and fixes a **Live Translate restart loop on machines without an NVIDIA GPU**. It carries forward every change from v0.1.0-beta.20.

## What's new since v0.1.0-beta.20

### AI Analyst (new)

A new **AI Analyst** page reviews your own trade history and explains it in plain language: result, win rate versus break-even, long/short mix, drawdown, how trades closed, and which accounts or symbols carry the result. Everything is **read-only** — it never places, changes or closes an order and never touches risk settings.

- **Numbers are computed by code, not by the model.** The verdict, the headline figures, the strengths and the weaknesses are calculated from your data; the AI only writes a short commentary on top, and the commentary is checked against those numbers before it is shown.
- **Final result first.** The headline is the change in your real account balance (deposits and withdrawals excluded), reconciled with the exchange's daily results, with an equity curve and daily profit/loss bars.
- **Scope you choose.** One account, or one combined report for all Demo or all Live accounts. Demo and Live are never mixed.
- **Runs on your machine.** It uses a local Ollama model by default; you can instead add your own OpenAI-compatible API key (stored encrypted in the local vault). Reports are generated as a background job and can take a few minutes on a small local model.
- Vietnamese and English reports.

See the [AI Analyst guide](/docs/ai-analyst-trade-review) for screenshots and a walkthrough. Treat it as a review aid, not advice: the commentary comes from a small model and can still suggest ideas the data does not support.

### Installer — downloads only the Live Translate images your machine can run (Linux)

The `.run` / `.deb` installer now reads your hardware **before** pulling images. A machine without a usable NVIDIA GPU no longer downloads the multi-GB CUDA translator image, and a machine below the RAM/CPU minimum also skips the full speech tier. The lite translator and every trading component are never skipped, and anything skipped is still pulled on demand later. To restore the old behavior set `WOLFBOT_ONECLICK_PULL_ALL_TIERS=1` for the install.

### Installer — safe bridge from containers to Ollama (Linux)

Containers reach the host's Ollama through `host.docker.internal`. By default Ollama listens only on `127.0.0.1`, so containers could not reach it unless you opened it to every network interface. The installer now sets up a small forwarder that listens **only on the private Docker bridge address** and forwards to `127.0.0.1:11434`, with a narrow firewall rule when `ufw` is active. It refuses wildcard and public addresses and is removed on uninstall. Disable it with `WOLFBOT_OLLAMA_BRIDGE=0`. If you later open Ollama on `0.0.0.0:11434` yourself, stop the bridge: `sudo systemctl disable --now wolfbot-ollama-bridge`.

### Daily ROI — missing days are filled in

If the PC was off for two or more days, the daily ROI job used to lose the days in between for good, which left holes in the equity curve. When the history has a gap, the job now asks the exchange for exactly the missing days, fills only the days the exchange returns, keeps every existing value, and recalculates cumulative figures from the first patched day. No gap means no extra exchange calls. Turn it off with `WOLFBOT_ROI_GAP_FILL=0`; limit brokers with `WOLFBOT_ROI_GAP_FILL_BROKERS`.

### Live Translate — no more restart loop without a GPU

On a machine without an NVIDIA GPU the container watchdog restarted the translator roughly every 10 minutes. It now only checks the GPU when the translator is actually running its GPU tier.

### Carried forward from v0.1.0-beta.20

- **Binance Portfolio Margin** stop-loss clamped to the symbol's minimum price; **OKX** `PAXGUSDT` aliasing.
- **Gate Account Connect**, hardened OKX/Gate TP/SL, BingX multi-asset collateral and Binance PM liabilities in equity, Binance `-1021` handling, Bitget UTA realized PnL.

## Highlights carried over from previous releases

### TradingView webhook automation

TradingView alerts flow through the real WolfBot command pipeline.

| TradingView payload action | WolfBot behavior |
|---|---|
| `buy` | queue/open long |
| `sell` | queue/open short |
| `close_long` | close an existing long side |
| `close_short` | close an existing short side |

The webhook route validates the source secret, deduplicates repeated signals, writes an internal command, and then lets the normal dispatcher, execution layer and risk controls handle the action. TradingView does not receive exchange API keys and does not talk to exchanges directly.

### One platform for crypto, futures and MT5

- Binance
- Bybit
- BingX
- KuCoin
- Bitget
- OKX
- Gate (Account Connect)
- MT5 brokers for Forex, Gold, Indices and broker-dependent CFDs

Use Simulation or broker demo accounts first. Move to live accounts only after verifying your setup and risk controls.

### Digest-pinned, signed runtime images

The release manifest pins the runtime by immutable container image digests, including the translator tiers that power Live Translate. The installer pulls the exact image set signed for this release, not a mutable tag that can drift later.

## Who should use this release

Use v0.1.0-beta.21 if you want to:

- run a free self-hosted trading platform on Ubuntu, Debian, a Linux VPS or Windows (Docker edition);
- get a plain-language, read-only review of your own trade history with the AI Analyst;
- install on a laptop without an NVIDIA GPU without downloading the multi-GB GPU translator image;
- keep the daily ROI curve complete even when the PC is sometimes switched off;
- set Model Type, Trailing and Account Profit Lock per account from the dashboard;
- connect crypto/futures accounts and MT5 from one dashboard.

Already running v0.1.0-beta.20 or earlier on Linux? Install the new `.deb` or `.run` over your existing install — no need to uninstall first, and your data/config stay in place. On Windows the installer is unchanged from v0.1.0-beta.20 (Docker edition, same WolfBot as Linux); it cannot run next to the older Windows "Native" build (v0.1.0-beta.15), so uninstall that one first.

## Security model

WolfBot Community is designed to be self-hosted and non-custodial:

- your API keys stay on your machine;
- use trade-only API keys;
- withdrawal and transfer permissions should remain disabled;
- installers publish SHA256 checksums;
- runtime images are digest-pinned and cryptographically signed;
- TradingView alerts use a WolfBot source secret and never contain broker credentials;
- Live Translate runs entirely locally — no audio or text leaves your machine.

## Recommended first-run path

- Install the signed Linux `.deb` or `.run` package from this release.
- Open the local setup wizard at `http://127.0.0.1:8080/portal/local/setup`.
- Start with Simulation or a broker demo account to learn the workflow.
- Use trade-only API keys for live exchanges and keep withdrawal permissions disabled.
- Verify checksums before installing and keep the signed release files for auditability.
