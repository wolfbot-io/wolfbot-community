# WolfBot Community v0.1.0-beta.2

**Tested with WolfBot Community v0.1.0-beta.2** · Last updated: 2026-08-24

WolfBot Community v0.1.0-beta.2 is the latest public release of the free, self-hosted WolfBot trading platform for Windows and Linux users. This Linux-first release publishes signed installers today, runs the stack locally on your machine or VPS, and brings TradingView webhook automation into the same risk-aware execution path as manual and strategy-driven trading.

Windows remains part of the WolfBot Community product roadmap, with the Windows Setup.exe installer planned as a dedicated follow-up release.

This release is for traders who want one self-hosted platform for crypto exchanges, futures accounts, MT5 markets, TradingView alerts, simulation, Smart Terminal execution, portfolio monitoring and risk controls.

## What is new in this release

### TradingView webhook automation is real

TradingView alerts can now create WolfBot commands for:

| TradingView action | WolfBot command |
|---|---|
| `buy` | open long |
| `sell` | open short |
| `close_long` | close an existing long side |
| `close_short` | close an existing short side |

The webhook does not trade directly from TradingView. WolfBot validates the source secret, deduplicates the signal, writes the command to the internal ledger, then lets the normal dispatcher and risk controls execute it on the selected account.

Start here: [TradingView Webhook to WolfBot Community](/docs/tradingview).

| `wolfbot-oneclick-0.1.0-beta.2.run` | Self-extracting Linux install path | `16896217809f8525f65d806a3cb76d5856d3fa6c51fabe037b92bcd87441f046` |

Download: [WolfBot Community Download Center](/download).

Windows is still a target platform for WolfBot Community. The Windows install path remains documented for the follow-up installer release, while this release gives Linux desktop, workstation and VPS users the current install path.

### Digest-pinned Community runtime

The release manifest pins every service image by digest:

- engine
- control-api
- gateway
- webui
- financial-publisher
- periodic-jobs
- worker-supervisor
- outcome worker

That means the installer pulls the exact runtime image set that was signed for this release instead of a moving tag.

### Multi-broker trading platform

The Community edition continues to target one interface for:

- Binance
- Bybit
- BingX
- KuCoin
- Bitget
- MT5 brokers for Forex, Gold, Indices and broker-dependent CFDs

Use a demo or simulation workflow first, then connect live accounts with trade-only API keys when ready.

### Unified risk and simulation-first workflow

WolfBot Community is built around a risk-aware workflow:

1. Install locally.
2. Open the setup wizard.
3. Connect a simulation or demo account.
4. Test Smart Terminal, TradingView alerts or strategies.
5. Add a live, trade-only API key only after the behavior is understood.

The same order path protects manual orders, automated strategies and TradingView webhook commands.

## Install

Ubuntu/Debian:

```bash
sudo apt install ./WolfBot-Setup-linux-amd64.deb
```

Self-extracting installer:

```bash
chmod +x wolfbot-oneclick-0.1.0-beta.2.run
sudo WOLFBOT_ONECLICK_CONFIRM=INSTALL ./wolfbot-oneclick-0.1.0-beta.2.run
```

After install, open:

```text
http://127.0.0.1:8080/portal/local/setup
```

## Verify before installing

On Linux:

```bash
sha256sum WolfBot-Setup-linux-amd64.deb
sha256sum wolfbot-oneclick-0.1.0-beta.2.run
```

Compare the values with the checksums above or the `SHA256SUMS` file attached to the GitHub release.

Read more: [How to verify a downloaded trading bot](/docs/how-to-verify-a-downloaded-trading-bot).
