# Community vs Cloud

**どちらの WolfBot があなたに適していますか?**

両エディションは同じ統合取引エンジンを共有します。暗号通貨 + 先物 + MT5 — 1 つのプラットフォーム、すべての市場。

---

## 一目でわかる比較

| | WolfBot Community | WolfBot Cloud |
|---|---|---|
| **コスト** | 無料 | サブスクリプション |
| **ホスティング** | 自分のマシン | WolfBot.io 管理 |
| **セットアップ** | インストール & 構成 | 数分で準備完了 |
| **アップデート** | チャネルベースの自動更新 | 自動 |
| **インフラ** | 自分で管理 | 私たちが管理 |
| **サポート** | コミュニティ (Discussions) | 直接サポート |
| **カスタマイズ** | フルアクセス | プラットフォーム内 |
| **稼働時間** | 自己責任 | 24/7 マネージド |

---

## WolfBot Community

### 最適な方:
- インフラを完全に管理したいトレーダー
- セルフホスティングに慣れた技術ユーザー
- WolfBot を無料で試したい方 — 暗号通貨と MT5 のための 1 つのプラットフォーム
- 個人 PC または VPS での運用
- コスト重視のトレーダー

### 自分が責任を持つこと:
- ソフトウェアのインストール
- マシンの稼働維持
- バックアップ管理
- ネットワーク/ファイアウォール構成
- アップデート適用 (ワンクリックだが手動)

### 主な利点:
- ✅ 完全に無料
- ✅ データは自分のマシンに保持
- ✅ サブスクリプション義務なし
- ✅ Cloud と同じ取引エンジン — 暗号通貨 + 先物 + MT5
- ✅ フル API アクセス
- ✅ GitHub を通じたオープン開発

---

## WolfBot Cloud

### 最適な方:
- マネージドでメンテナンス不要の体験を求めるトレーダー
- サーバーを管理したくない方
- PC/VPS 管理なしの 24/7 取引
- 優先サポートが必要
- チームおよびマルチアカウント管理

### WolfBot.io が処理すること:
- サーバーホスティングと稼働時間
- インフラメンテナンス
- 自動アップデート
- バックアップと災害復旧
- セキュリティ監視
- パフォーマンス最適化

### 主な利点:
- ✅ インストール不要
- ✅ 常にオンライン — 24/7 運用
- ✅ チームからの直接サポート
- ✅ すべて自動
- ✅ マルチアカウントダッシュボード
- ✅ 高度な分析

## 一般的な移行パス

### Community 開始 → Cloud へ

多くのユーザーが Community から始めます:
1. WolfBot を無料でリスクなくテスト (無料、デモ口座)
2. 暗号通貨および MT5 市場で戦略を検証
3. 統合インターフェースに慣れる
4. マネージド 24/7 取引の準備ができたら Cloud へ移行

### Cloud → Community

Cloud ユーザーが Community を使う場合:
- 開発とテスト
- ローカルで独自戦略を実行
- バックアップ取引環境
- プライバシー重視のオペレーション

---

## 両方使えますか?

はい! 両方を運用できます:

- **Community** はテスト/開発用 PC で
- **Cloud** は 24/7 本番取引用

別々のインストールであり、互いに干渉しません。

## よくある質問

**Q: Community は Cloud の「制限版」ですか?**
いいえ。Community は同じ取引エンジン、戦略、ブローカーサポートを持ちます。同じ統合プラットフォーム — 暗号通貨、先物、MT5。違いはホスティングとサポートです。

**Q: Community はいつまでも無料ですか?**
はい。WolfBot Community は、すべての人に無料のセルフホスト型統合取引プラットフォームを提供するという約束です。

**Q: Community から Cloud へ移行できますか?**
はい。設定と戦略をエクスポートすれば、チームが移行をサポートします。

**Q: Cloud に Community にない機能はありますか?**
Cloud にはマネージドホスティング、チーム機能、高度な分析、直接サポートが含まれます。すべての市場サポートを含むコア取引エンジンは同一です。
