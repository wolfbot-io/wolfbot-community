# 取引ドローダウンを減らす方法

**WolfBot Community v0.1.0-beta.4 でテスト済み** · 最終更新: 2026-08-15

## ドローダウンとは?

ドローダウンは、高値から安値までの口座の下落です。経験した **最悪の損失区間** を測定します。

```text
$10.000 → $15.000 (高値) → $11.000 (安値)
ドローダウン = (15.000 - 11.000) / 15.000 = 26,7%
```

ドローダウンが低いほど、より冷静に取引でき — 不可避な損失区間を生き延びる可能性も高くなります。

## このガイドの対象者

- **すべてのトレーダー:** 統計を学ばずにドローダウンを下げる6つの実践可能な手順。
- **技術ユーザー:** 背後にある数学と、WolfBot がこれらのルールを自動で強制する方法。

## 低いドローダウンが重要な理由

| ドローダウン | 必要な回復 | 感情的な圧力 |
|---|---|---|
| 10% | 11% の利益 | 低い |
| 25% | 33% の利益 | 明確 |
| 50% | 100% の利益 | 高い |
| 75% | 300% の利益 | 極度 |

深く落ちるほど回復は難しくなり — **そして** 感情的に諦める可能性も高くなります。

## ドローダウンを下げる6つの手順

### 1. ポジションサイズを制限

ドローダウン管理で最も効果的な手段。

**ルール:** 単一取引で口座の 1〜2% 以上をリスクにさらさないでください。

```text
口座 $10.000 → 1取引あたりのリスク = $100–$200
```

- 2% リスク時: 10 連敗でも = -20% (痛いが耐えられる)
- 10% リスク時: 10 連敗 = ほぼ破産

**WolfBot で:** `Max position % of balance` を 2〜5% に設定。

### 2. 全ポジションにストップロスを使う

ストップロスは単一取引の損失を既知の額に制限します。

**WolfBot で:** Smart Terminal が全ポジションに既定でストップロスを設定します。決して外さないでください。

### 3. 市場全体に分散

1つの市場に全てを賭けないでください。WolfBot は暗号通貨 **と** MT5(外国為替、金、指数)を取引します — 相関の低い商品にリスクを分散しましょう。

**助けになる理由:** ある市場が下がっても、別の市場が上がって全体のドローダウンを和らげることができます。

### 4. 損失後のクールダウンを使う

損失取引後は感情的な決定の可能性が高まります。休止を強制しましょう。

**WolfBot で:** `After loss cooldown` を 5〜15 分に設定。

### 5. 1日の損失上限を設定

取引が止まる最大の1日損失を決めます。

**WolfBot で:** `Daily loss limit` を 5〜10% に設定。その後、取引は自動で一時停止します。

### 6. レバレッジを減らす

レバレッジは利益 **と** 損失を増幅します。

| レバレッジ | 価格変動 | 口座への影響 |
|---|---|---|
| 1x | 10% | 10% |
| 5x | 10% | 50% |
| 10x | 10% | 100% (破産) |

**WolfBot で:** `Max leverage` を保守的に設定 (初心者は 1x–3x)。

## 回復の数学

損失後、元に戻るにはより多くの利益が必要です:

```text
損失 10% → 損益分岐まで +11% 必要
損失 20% → +25% 必要
損失 30% → +43% 必要
損失 50% → +100% 必要
```

ドローダウンが深いほど回復曲線は急になります — ドローダウンを小さく保つべきもう一つの理由。

## 前/後の例

### 前 (高いドローダウン)

```
ポジション: 口座の 20%
レバレッジ: 10x
ストップ: しばしば無視
損失: 休止なし
結果: 悪い局面で 60% ドローダウン
```

### 後 (低いドローダウン)

```
ポジション: 口座の 3%
レバレッジ: 2x
ストップ: 常に設定
損失: 10分のクールダウン
結果: 同じ局面で 15% ドローダウン
```

同じ戦略、同じ市場環境 — まったく異なるリスクプロファイル。

## WolfBot で実装

このガイドのすべては WolfBot のリスク管理で構成できます:

| 手順 | WolfBot 設定 |
|---|---|
| ポジションサイズ | `Max position %` |
| ストップロス | Smart Terminal (既定) |
| 分散 | 複数ブローカー/市場を接続 |
| クールダウン | `After loss cooldown` |
| 1日の上限 | `Daily loss limit` |
| レバレッジ | `Max leverage` |

> 完全な手順は [リスク管理ガイド →](/docs/risk-controls) 参照

## 考えるべきこと

ドローダウンは不可避ですが — その **大きさ** は自分の手にあります。諦める大半のトレーダーは、戦略のせいではなく、耐えられないほど大きいドローダウンのせいで諦めます。
