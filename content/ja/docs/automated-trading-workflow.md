# 自動取引ワークフロー

**WolfBot Community v0.1.0-p12-ghcr-rc17 でテスト済み** · 最終更新: 2026-08-15

## 概要

自動取引とは、事前に決めたルールに従ってソフトウェアが取引を実行することを意味します — 常に画面の前に座る必要はありません。WolfBot Community は、暗号通貨、先物、MT5(外国為替、金、指数)というすべての市場でこれらのルールを実行します。

## このガイドの対象者

- **すべてのトレーダー:** 最初のボットから実取引までの明確なワークフロー — プログラミング知識は不要。
- **技術ユーザー:** ルール、リスク管理、実行が WolfBot でどう連携するか理解。

## ワークフロー概要

```text
1. 戦略を選ぶ
   ↓
2. ボットを構成
   ↓
3. デモでテスト
   ↓
4. リスクを見直す
   ↓
5. 実取引へ切り替え
   ↓
6. 監視と調整
```

---

## ステップ 1: 戦略を選ぶ

自分に合う取引アプローチを選択:

| 戦略 | 説明 | 最適 |
|---|---|---|
| **グリッド取引** | 価格帯で安く買い、高く売る | レンジ相場 |
| **DCA** | 間隔を置いて買い、平均価格を下げる | トレンド相場 |
| **トレンドフォロー** | 上昇モメンタムで買い、下落で売る | 強いトレンド |
| **TP/SL 自動化** | 自動の利益/損失目標 | すべての戦略 |

---

## ステップ 2: ボットを構成

各ボットには動作を定義するパラメータがあります。正確なパラメータは戦略によって異なりますが、基本パターンは同じです。

### 主要パラメータ

| パラメータ | 説明 |
|---|---|
| **シンボル** | 取引する商品 (暗号通貨または MT5) |
| **方向** | ロング、ショート、または両方 |
| **ポジションサイズ** | 各取引のサイズ (リスク管理で制限) |
| **TP/SL** | 利益および損失目標 |
| **エントリールール** | 取引を開くタイミング |
| **決済ルール** | 取引を閉じるタイミング |

### 例: シンプルな DCA ボット

```
シンボル: BTC/USDT
方向: ロング
最初の買い: $100
追加買い: -5% の価格下落ごと
最大買い: 5回
テイクプロフィット: 平均価格から +3%
ストップロス: -10%
```

---

## ステップ 3: デモ口座でテスト

**常にデモ口座で最初にテストしてください。**

1. デモ/テストネット口座を接続 ([デモガイド](/docs/simulation) 参照)
2. ボットを作成しデモ口座に設定
3. 最低数日間実行
4. さまざまな市場状況でどう動作するか観察
5. TP/SL が期待通りに機能するか確認

> ⚠️ デモ口座はボットの **仕組み** を検証しますが、必ずしも **収益性** を検証しません。過去のパフォーマンスは将来の結果を保証しません。

---

## ステップ 4: リスクを見直す

実取引の前にリスク管理を確認:

- [ ] ポジションサイズ上限が保守的
- [ ] 1日の損失上限が設定済み
- [ ] クールダウンタイマーが有効
- [ ] 最大レバレッジが制限済み
- [ ] 全取引に TP/SL あり

> 完全な手順は [リスク管理ガイド →](/docs/risk-controls) 参照

---

## ステップ 5: 実取引へ切り替え

準備ができたら:

1. **Trade-Only** API キーで実口座を接続
2. **最小** ポジションサイズで開始
3. 一度に1つのボットを有効化
4. 最初の取引を注意深く監視
5. 信頼を築きながら徐々に拡大

---

## ステップ 6: 監視と調整

自動化は「放置していい」という意味ではありません。

### 定期的なチェック

- **毎日:** ボットが動作し、取引が期待通りに実行されているか確認
- **毎週:** パフォーマンスとドローダウンを確認
- **毎月:** 戦略の前提を見直し、パラメータを調整

### 介入すべきとき

- 上限を超える予期しない損失
- 市場レジームの変化 (強いトレンド → レンジ)
- ブローカー/MT5 条件の変更
- リスクに不安を感じる

---

## ベストプラクティス

1. **小さく始める** — 戦略が証明されるまで最小サイズ
2. **一度に1つの戦略** — 過度な複雑さを避ける
3. **記録をつける** — 何を変え、なぜ変えるかを記録
4. **規律を保つ** — 感情でルールから逸脱しない
5. **リスク管理を尊重** — 安全網です

---

## よくある落とし穴

| 落とし穴 | 回避法 |
|---|---|
| 大きすぎる開始 | 最小サイズで開始 |
| デモを飛ばす | 常にデモで先にテスト |
| リスク管理を無視 | 最初に構成 |
| 過剰取引 | クールダウンと1日上限を設定 |
| 戦略を諦める | 証明済み戦略に時間を与える |
