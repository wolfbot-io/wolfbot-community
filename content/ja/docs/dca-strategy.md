# DCA 戦略の説明

**WolfBot Community v0.1.0-p12-ghcr-rc21 でテスト済み** · 最終更新: 2026-08-15

## DCA とは?

DCA(ドルコスト平均法)は、価格に関係なく **一定間隔** で一定額を買う戦略です。取引では、価格が下がったときに追加購入して **平均価格を下げる** ことを意味することが多いです。

## このガイドの対象者

- **すべてのトレーダー:** DCA を簡単な言葉で理解 — 何か、いつ役立つか、いつ危険か。
- **技術ユーザー:** 背後にある数学と、WolfBot が DCA をリスク管理と組み合わせる方法。

---

## DCA の仕組み

### 基本原則

```text
BTC を $50.000 で $100 購入 (0,002 BTC)
価格が $45.000 に下落 → $100 追加購入 (0,00222 BTC)
価格が $40.000 に下落 → $100 追加購入 (0,0025 BTC)

平均価格: (100+100+100) / (0,002+0,00222+0,0025) = $44.590

価格が $45.000 に戻ると → 利益状態
(価格が最初の購入より低くても)
```

### 役立つ理由

1. **平均価格を下げる** — 損益分岐に必要な回復が減る
2. **タイミングを排除** — 底値を当てようとしない
3. **規律的** — 感情ではなくルール
4. **変動市場に適合** — 変動から利益

---

## DCA がうまく機能する場合

### 適している場合

- **レンジ相場** — 価格が範囲内で変動
- **長期積立** — 長期的価値を信じる
- **調整を伴うトレンド市場** — 上昇トレンドの押し目で買い

### 適さない場合

- **急落市場** — 「落ちてくるナイフを掴む」
- **崩壊する資産** — どんな平均価格も崩壊を救えない
- **資本が限られている場合** — DCA は余剰資金が必要

> ⚠️ DCA はストップロスの **代わりではありません**。エントリー戦略であり、リスク戦略ではありません。

## WolfBot の DCA

WolfBot は DCA をボット戦略としてサポートします:

### DCA ボットの構成

| パラメータ | 説明 | 例 |
|---|---|---|
| **シンボル** | 商品 (暗号通貨または MT5) | BTC/USDT |
| **最初の買い** | 初期ポジションサイズ | $100 |
| **間隔** | 追加購入のタイミング | -5% の価格下落 |
| **購入回数** | 最大追加購入 | 5回 |
| **TP** | 利益目標 (平均比) | +3% |
| **SL** | 損失上限 | -10% |

### 構成例

```text
シンボル: BTC/USDT
最初の買い: $100
追加購入: -5% ごと
最大購入: 5回 (合計最大: $500)
テイクプロフィット: 平均価格から +3%
ストップロス: -10%
```

## DCA のリスク

### 1. 資本枯渇

価格が下がり続けると「追加購入」で資本を使い果たします。

**保護:** 最大購入回数と総資本上限を設定。

### 2. 落ちてくるナイフ

本当の暴落では価格が下がり続ける — すべての追加購入が損失を出します。

**保護:** 長期的に信じる市場でのみ DCA を使う。常にストップロスを設定。

### 3. 過剰エクスポージャー

多すぎる DCA 購入が安全水準を超えて総エクスポージャーを押し上げることがあります。

**保護:** リスク管理が総エクスポージャーを自動で制限。

---

## DCA vs 一括購入

| 観点 | DCA | 一括購入 |
|---|---|---|
| **タイミング** | 完璧なタイミング不要 | タイミングが重要 |
| **平均価格** | 時間とともに移動 | 購入時に固定 |
| **感情的ストレス** | 低い | 高い |
| **資本要件** | 余剰資金が必要 | 一度に全額 |
| **最適** | 変動/レンジ市場 | 強い確信 |

---

## ベストプラクティス

1. **最大資本投入を設定** — 事前に上限を知る
2. **ストップロスを設定** — DCA は SL の代わりにならない
3. **間隔を慎重に選ぶ** — 狭すぎると過剰取引、広すぎると効果が薄い
4. **デモで始める** — DCA 設定をリスクなしでテスト
5. **リスク管理を尊重** — 総エクスポージャーを制限
