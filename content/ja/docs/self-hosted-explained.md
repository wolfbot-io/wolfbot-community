# セルフホスティングとは?

**WolfBot Community v0.1.0-p12-ghcr-rc20 でテスト済み** · 最終更新: 2026-08-15

## 核となる考え方

WolfBot Community は **セルフホスト** です — つまり、ソフトウェアは私たちのサーバーではなく **自分のマシン**(PC またはサーバー)で実行されます。自分でインストールし、自分で管理し、データは自分の手元に残ります。

## このガイドの対象者

- **管理したい方:** 取引ボットを自分で運用する意味と、多くのトレーダーが好む理由を理解。
- **技術的な背景のある方:** データの保存場所、バックアップ方法、24/7 運用方法など、正確な詳細を下記で確認。

## セルフホスティングの意味

WolfBot Community を使うと:

1. **ソフトウェアをダウンロード** — GitHub ページから
2. **インストール** — Windows または Linux マシンに
3. **口座を接続** — API キーは自分のマシンに保持
4. **実行** — マシンがオンの間はいつでも取引可能

## なぜセルフホストなのか?

### 1. 完全な管理

- アップデートを適用するタイミングを自分で決める
- すべてのリスク設定を自分で構成
- 設定を直接確認・バックアップできる
- サードパーティのスケジュールに依存しない

### 2. プライバシー

- API キーは自分のマシンに暗号化して保管
- 取引履歴と設定は自分のマシンから出ない
- サードパーティサーバーが取引データを見ない

### 3. コスト

- WolfBot Community は無料
- マシン代のみ支払う (VPS 使用時)
- サブスクリプション料なし、隠れたコストなし

### 4. 透明性

- 設定ファイルを確認できる
- ソフトウェアが何をするか追跡できる
- 開発が GitHub で公開

## セルフホスティングの要件

### 最小要件

| 要件 | 最小 | 推奨 |
|---|---|---|
| **OS** | Windows 10+ または Ubuntu 20.04+ | 最新の安定版 |
| **RAM** | 2 GB | 4 GB |
| **ストレージ** | 1 GB 空き | 5 GB 空き |
| **ネットワーク** | インターネット | 有線接続 |

### 自分の責任

- ✅ マシンをオンにして接続を維持
- ✅ アップデート適用 (ワンクリック)
- ✅ 定期的なバックアップ
- ✅ 基本的なセキュリティ衛生

> 💡 **技術ユーザー向け:** セルフホスティングは自分がシステム管理者になることを意味します。WolfBot はマシン上でサービス/プロセスとして動作し、設定と暗号化された API シークレットをローカルに保存し、ブローカー API へアウトバウンド接続します。インバウンドサーバーはありません — 外部から到達可能なものは公開されません。

## セルフホスティング vs Cloud

| 観点 | セルフホスト (Community) | Cloud |
|---|---|---|
| **コスト** | 無料 | サブスクリプション |
| **管理** | 完全 | 限定的 |
| **責任** | 自分 | プロバイダー |
| **プライバシー** | 完全 | 共有 |
| **セットアップ** | 手動 | 即時 |

完全な比較は [Community vs Cloud →](/community-vs-cloud) 参照

## セルフホスティングが自分に合うか?

### セルフホスティングを選ぶ場合:
- ✅ ボットを完全に管理したい
- ✅ 基本的なコンピュータ管理に慣れている
- ✅ 無料オプションを好む
- ✅ データを非公開にしたい

### Cloud を検討する場合:
- ⚠️ マシンを管理したくない
- ⚠️ 自前ハードウェアなしで 24/7 稼働時間が必要
- ⚠️ 直接サポートが必要

## 技術ユーザー向け

セルフホスティングで重要な詳細:

- **データパス:** WolfBot は設定を `/opt/wolfbot/`(Linux)または `%USERPROFILE%\.wolfbot\`(Windows)に保存します。バックアップはサブディレクトリに保存されます。
- **暗号化:** API シークレットはディスクに書き込む前に暗号化されます; 設定ファイルに平文で保存されません。
- **ネットワーク:** ブローカー API へのアウトバウンド接続のみ。インバウンドアクセス用のポートは開かれません。
- **24/7 運用:** 中断のない取引には VPS を使用 — [VPS で 24/7 実行 →](/docs/run-24-7-on-a-vps)。
